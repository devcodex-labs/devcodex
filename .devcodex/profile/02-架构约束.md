# 02 — 架构约束

## 顶层目录结构

```
devcodex/
├── agents/                  # Agent 定义文件（.agent.md）
│   └── devcodex.agent.md    # 唯一 Agent，含全工作流路由
├── skills/                  # Skill 文件（按领域分组）
│   ├── core/                # 核心技能（compliance/memory/report/cp-gate/intent/summary/plan）
│   ├── routing/             # 路由技能（load-profile）
│   ├── dev/                 # 开发工作流技能（8 子类型）
│   ├── fix/                 # 修复工作流技能（3 子类型）
│   ├── audit/               # 审计工作流技能
│   ├── analyze/             # 分析工作流技能
│   ├── self-fix/            # 规范自修复技能
│   ├── cross/               # 跨工作流共用技能（api-verification/document-sync/impact-review）
│   └── token/               # Token 权限验证技能
├── instructions/            # 全局 Instructions（按优先级编号，英文）
│   └── 00- ~ 17-*.instructions.md
├── prompts/                 # Prompt 模板文件（.prompt.md，英文）
├── hooks/                   # Agent Hooks
├── auth/                    # 授权相关
├── commercial/              # 商业化相关
├── data/                    # 运行时数据（violations/pending-fixes/gap-registry）
├── tools/                   # 内部工具（审计/迁移脚本，不发布 npm）
├── assets/                  # 品牌资产（icon/banner/screenshot）
├── website/                 # 文档站（Rspress，中文为主）
│   └── docs/
│       ├── requirements/    # ← 所有需求文档（唯一需求来源）
│       ├── progress/        # 开发进度追踪
│       ├── guide/           # 使用指南
│       └── specs/           # 规范镜像（英文规范的中文翻译）
├── .devcodex/               # 本项目自身的 DevCodex 产物
│   ├── profile/             # 项目规范（本目录）
│   └── .memory/             # AI 记忆（.gitignore 排除）
├── v0.03/                   # v0.0.3 存档快照（重构参考）
├── index.js                 # CLI 入口
├── package.json
├── plugin.json
└── RULES.md
```

## 模块职责边界

| 模块 | 职责 | 禁止 |
|------|------|------|
| `agents/` | 路由入口，调用 Skill | 直接实现业务逻辑 |
| `skills/` | 具体执行能力 | 调用其他 Skill（除非明确声明）|
| `instructions/` | 全局约束注入（英文）| 工作流特定逻辑 |
| `prompts/` | 用户交互模板（英文）| 执行代码或逻辑 |
| `index.js` | 文件复制安装器 | 业务逻辑、网络请求 |
| `website/docs/requirements/` | 需求文档（唯一来源）| 散落在代码注释中 |

## Instructions 编号规则

| 编号范围 | 类别 |
|---------|------|
| 00-09 | 安全与通用（全局注入）|
| 10-14 | 工作流规则（dev/fix/analyze/audit/self-fix）|
| 15-17 | 产物规则（memory/report/compliance）|

## Skill 文件规范

- 路径：`skills/<domain>/<skill-name>/SKILL.md`
- 必须包含 YAML frontmatter：`name` + `description`
- `name` 字段必须与目录名完全一致
- 单文件 ≤ 500 行

## 关键约束

- ⛔ `plugin.json` 的 `version` 必须与 `package.json` 保持同步
- ⛔ 规范文件（agents/skills/instructions）统一用英文编写
- ⛔ 需求变更必须更新 `website/docs/requirements/` 对应文件
- ⚠️ 修改任何规范文件后，必须运行 `devcodex update` 推送到工作区
