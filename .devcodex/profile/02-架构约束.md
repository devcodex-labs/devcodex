# 02 — 架构约束

## 顶层目录结构

```
devcodex/
├── agents/                  # Agent 定义文件（.agent.md）
│   ├── devcodex.agent.md    # 确认模式 Agent（主入口）
│   └── devcodex-auto.agent.md  # 全自动模式 Agent
├── skills/                  # Skill 文件（扁平结构，每个 Skill 一个目录）
│   ├── compliance/          # 合规检查（FC/SC/RC 三层）
│   ├── cp-gate/             # CP 确认门控
│   ├── dev-default/         # 开发工作流默认子类型
│   ├── fix-default/         # 修复工作流默认子类型
│   ├── intent/              # 意图识别（三问法）
│   ├── load-profile/        # Profile 加载 + ENV_MODE 注入
│   ├── memory/              # 记忆读写
│   ├── plan/                # 执行计划（兜底路由）
│   ├── report/              # 报告生成
│   ├── routing/             # 路由映射参考
│   └── summary/             # 会话摘要写入
├── instructions/            # 全局 Instructions（按优先级编号，中文）
│   └── 00- ~ 17-*.instructions.md
├── prompts/                 # Prompt 模板文件（.prompt.md，中文）20 个
├── data/                    # 运行时数据（violations/pending-fixes/gap-registry）
├── website/                 # 文档站（Rspress，中文为主）
│   └── docs/
│       └── versions/v1/1.0.0/
│           ├── requirements/ # ← 所有需求文档（唯一需求来源）
│           └── dev/          # 开发文档（实施计划/Stage）
├── .devcodex/               # 本项目自身的 DevCodex 产物
│   ├── profile/             # 项目规范（本目录）
│   └── .memory/             # AI 记忆（.gitignore 排除）
├── v0.03/                   # v0.0.3 存档快照（重构参考）
├── index.js                 # CLI 入口
├── package.json
├── plugin.json
└── RULES.md
```

## 模块职责边界

| 模块 | 职责 | 禁止 |
|------|------|------|
| `agents/` | 路由入口，调用 Skill | 直接实现业务逻辑 |
| `skills/` | 具体执行能力 | 调用其他 Skill（除非明确声明）|
| `instructions/` | 全局约束注入（中文）| 工作流特定逻辑 |
| `prompts/` | 用户交互模板（中文）| 执行代码或逻辑 |
| `index.js` | 文件复制安装器 | 业务逻辑、网络请求 |
| `website/docs/versions/v1/1.0.0/requirements/` | 需求文档（唯一来源）| 散落在代码注释中 |

## Instructions 编号规则

| 编号范围 | 类别 |
|---------|------|
| 00-09 | 安全与通用（全局注入）|
| 10-14 | 工作流规则（dev/fix/analyze/audit/self-fix）|
| 15-17 | 产物规则（memory/report/compliance）|

## Skill 文件规范

- 路径：`skills/<skill-name>/SKILL.md`
- 必须包含 YAML frontmatter：`name` + `description`
- `name` 字段必须与目录名完全一致
- 单文件 ≤ 500 行

## 关键约束

- ⛔ `plugin.json` 的 `version` 必须与 `package.json` 保持同步
- ⛔ 规范文件（agents/skills/instructions）统一用中文编写
- ⛔ 需求变更必须更新 `website/docs/versions/v1/1.0.0/requirements/` 对应文件
- ⚠️ 修改任何规范文件后，必须运行 `devcodex update` 推送到工作区
