# 02 — 架构约束

## 顶层目录结构

```
devcodex/
├── agents/                  # Agent 定义文件（.agent.md）
│   └── devcodex.agent.md    # 唯一 Agent，含全工作流路由
├── skills/                  # Skill 文件（按领域分组）
│   ├── core/                # 核心技术技能（compliance/memory/report/...）
│   ├── routing/             # 路由技能（intent/load-profile/...）
│   ├── dev/                 # 开发工作流技能
│   ├── fix/                 # 修复工作流技能
│   ├── audit/               # 审计工作流技能
│   ├── analyze/             # 分析工作流技能
│   ├── self-fix/            # 规范自修复技能
│   ├── cross/               # 跨工作流共用技能（api-verification/document-sync/...）
│   └── token/               # Token 权限验证技能
├── instructions/            # 全局 Instructions（按优先级编号）
│   └── 00- ~ 17-*.instructions.md
├── prompts/                 # Prompt 模板文件（.prompt.md）
├── hooks/                   # Agent Hooks（devcodex-hooks.json）
├── auth/                    # 授权相关
├── commercial/              # 商业化相关
├── data/                    # 运行时数据（violations/pending-fixes/gap-registry）
├── tools/                   # 内部工具（审计/迁移脚本，不发布到 npm）
├── assets/                  # 品牌资产（icon/banner/screenshot）
├── .devcodex/               # 本项目自身的 DevCodex 产物
│   ├── profile/             # 项目规范（本目录）
│   └── .memory/          # AI 记忆（.gitignore 排除）
├── index.js                 # CLI 入口（init/update/status）
├── package.json
├── plugin.json              # DevCodex 插件元数据
└── RULES.md                 # 顶层规则说明
```

## 模块职责边界

| 模块 | 职责 | 禁止 |
|------|------|------|
| `agents/` | 路由入口，调用 Skill | 直接实现业务逻辑 |
| `skills/` | 具体执行能力 | 调用其他 Skill（除非明确声明）|
| `instructions/` | 全局约束注入 | 工作流特定的逻辑 |
| `prompts/` | 用户交互模板 | 包含执行代码或逻辑 |
| `index.js` | 文件复制安装器 | 业务逻辑、网络请求 |
| `tools/` | 开发期工具 | 被 CLI 或 Agent 调用 |

## CLI 安装器流程

```
devcodex init [--force] [--dry-run]
      ↓
扫描 SOURCES 数组（agents/skills/instructions/prompts/hooks/...）
      ↓
确定目标目录（.github/）
      ↓
逐文件复制（dry-run 模式仅输出计划）
      ↓
输出统计（已安装/已跳过/已更新）
```

`devcodex update` = `devcodex init --force`（强制覆盖）

## Skill 文件规范

每个 Skill 必须包含：

```markdown
---
name: <skill-name>
description: <简要描述>
---
# Skill 标题
...
```

- 文件名：`SKILL.md`
- 路径：`skills/<domain>/<skill-name>/SKILL.md`
- `name` 字段必须与目录名完全一致

## Instructions 编号规则

| 编号范围 | 类别 |
|---------|------|
| 00-09 | 安全与通用（全局注入） |
| 10-12 | 工作流规则（dev/fix/analyze/audit/self-fix）|
| 13-17 | 产物规则（report/memory/output-paths/compliance）|

## 关键约束

- ⛔ 禁止在 `index.js` 中硬编码业务逻辑（只做文件复制）
- ⛔ 禁止修改 `tools/migrate-*.js` 以外的工具为可发布文件
- ⛔ `plugin.json` 的 `version` 必须始终与 `package.json` 同步
- ⚠️ 修改任何规范文件后，必须同步运行 `devcodex update` 推送到工作区
