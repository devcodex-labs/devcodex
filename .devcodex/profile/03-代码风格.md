# 03 — 代码风格

## JavaScript（index.js / tools/）

### 基础规范

| 项目 | 规范 |
|------|------|
| **缩进** | 2 个空格 |
| **引号** | 单引号（`'`） |
| **分号** | 无分号 |
| **模块系统** | CommonJS（`require`/`module.exports`） |
| **行尾换行** | 文件末尾保留一个空行 |
| **最大行长** | 120 字符（软限制） |

### 命名约定

| 类型 | 风格 | 示例 |
|------|------|------|
| 变量/函数 | camelCase | `copyFile`, `targetDir` |
| 常量 | UPPER_SNAKE | `SOURCES`, `DEFAULT_TARGET` |
| 文件名（JS）| kebab-case | `v5-full-audit.js` |

### 注释规范

- 只在需要解释"为什么"时添加注释，不注释显而易见的逻辑
- 顶部保留 shebang（`#!/usr/bin/env node`）
- 函数级注释使用单行 `//`，不用 JSDoc（项目无 TypeScript）

### 错误处理

```js
// ✅ 正确：输出到 stderr，exit code 非零
console.error('Error:', err.message)
process.exit(1)

// ❌ 错误：静默失败或 throw 到顶层
throw err
```

## Markdown 规范文件（agents/skills/instructions/prompts/）

### Frontmatter

```yaml
---
name: skill-name          # 必须与目录名一致（Skill 文件）
description: 简短描述      # 不超过 50 字
applyTo: "**"             # Instructions 专用
---
```

### 内容规范

- 标题层级：从 `##` 开始（`#` 留给文件标题）
- 表格：必须包含表头，列对齐
- 代码块：必须标注语言（```js / ```yaml / ```bash）
- 列表：优先使用 `-`，嵌套最多 2 级
- 新建 `.md` 文件不超过 500 行（C13 约束）
- 文件末尾保留一个空行

### 文件命名

| 目录 | 命名规则 | 示例 |
|------|---------|------|
| `skills/<domain>/<name>/` | 目录名 kebab-case，文件名 `SKILL.md` | `dev-default/SKILL.md` |
| `instructions/` | `NN-<kebab-name>.instructions.md` | `10-dev.instructions.md` |
| `prompts/` | `<kebab-name>.prompt.md` | `requirement.prompt.md` |
| `agents/` | `<kebab-name>.agent.md` | `devcodex.agent.md` |

## 禁止事项

| 禁止 | 原因 |
|------|------|
| 硬编码 API Key / Token / 密码 | S02 安全底线 |
| 整文件覆盖现有 `.md` | S04 安全底线，必须增量编辑 |
| `console.log` 混入 `stderr` 流程输出 | 会干扰 CI 捕获 |
| 在 `index.js` 中使用第三方模块 | 保持零依赖 CLI |
| `tools/migrate-*.js` 以外工具调用网络 | 离线安装场景 |
| Markdown 文件使用 `Set-Content`/`sed -i` 修改 | C09 — 破坏 UTF-8 编码 |

## 版本控制

- `CHANGELOG.md`：顶层简要记录，每个 MINOR/MAJOR 版本一行
- `changelogs/vX.Y.Z.md`：详细变更，每个版本独立文件
- `PATCH` 版本追加到最近 MINOR 的 changelogs 文件
- commit 信息格式：`type(scope): 简短描述`（中英文均可）
