# 03 — 代码风格

## JavaScript（index.js / tools/）

| 项目 | 规范 |
|------|------|
| **缩进** | 2 个空格 |
| **引号** | 单引号（`'`） |
| **分号** | 无分号 |
| **模块系统** | CommonJS（`require`/`module.exports`） |
| **行尾换行** | 文件末尾保留一个空行 |
| **最大行长** | 120 字符（软限制） |

### 命名约定

| 类型 | 风格 | 示例 |
|------|------|------|
| 变量/函数 | camelCase | `copyFile`, `targetDir` |
| 常量 | UPPER_SNAKE | `SOURCES`, `PKG_ROOT` |
| 文件名（JS）| kebab-case | `v5-full-audit.js` |

### 注释规范

- 只在需要解释"为什么"时添加注释，不注释显而易见的逻辑
- 顶部保留 shebang（`#!/usr/bin/env node`）
- 使用单行 `//`，不用 JSDoc

### 错误处理

```js
// ✅ 正确
console.error('Error:', err.message)
process.exit(1)

// ❌ 错误：静默失败或 throw 到顶层
throw err
```

## Markdown 规范文件（agents/skills/instructions/prompts/）

### Frontmatter

```yaml
---
name: skill-name       # Skill 文件必填，必须与目录名一致
description: 简短描述   # 不超过 50 字
applyTo: "**"          # Instructions 专用
---
```

### 内容规范

- 语言：**中文**（agents/skills/instructions/prompts 统一中文编写）
- 标题层级：从 `##` 开始（`#` 留给文件标题）
- 代码块：必须标注语言（` ```js ` / ` ```yaml ` / ` ```bash `）
- 列表：优先 `-`，嵌套最多 2 级
- 新建 `.md` 文件不超过 500 行（C13 约束）

### 文件命名

| 目录 | 命名规则 | 示例 |
|------|---------|------|
| `skills/<name>/` | 目录名 kebab-case，文件 `SKILL.md` | `dev-default/SKILL.md` |
| `instructions/` | `NN-<kebab>.instructions.md` | `10-dev.instructions.md` |
| `prompts/` | `<kebab>.prompt.md` | `requirement.prompt.md` |
| `agents/` | `<kebab>.agent.md` | `devcodex.agent.md` |

## 禁止事项

| 禁止 | 原因 |
|------|------|
| 硬编码 API Key / Token / 密码 | S02 安全底线 |
| 整文件覆盖现有 `.md` | S04 安全底线，必须增量编辑 |
| `index.js` 中使用第三方模块 | 保持零依赖 CLI |
| Markdown 文件用 `Set-Content`/`sed -i` 修改 | C09 — 破坏 UTF-8 编码 |
| 规范文件用英文编写 | 统一使用中文（与 01-项目信息.md/02-架构约束.md 保持一致） |
