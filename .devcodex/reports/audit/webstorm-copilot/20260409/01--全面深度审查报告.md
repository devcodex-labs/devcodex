## 发现与修复详情

### 🔴 F-01 BOM 不一致（D1）

| 验证 | 结论 |
|------|------|
| 合理性 | 4 个 prompt 文件含 UTF-8 BOM，其余 66 个 .md 文件均无 BOM |
| 可实施性 | 直接移除 BOM 字节前缀，零风险 |
| 收益 | 消除编码不一致，避免某些解析器兼容问题 |

**影响文件**：
- `prompts/agent-summary.prompt.md`
- `prompts/memory-session.prompt.md`
- `prompts/precheck-status.prompt.md`
- `prompts/reply-summary.prompt.md`

**修复**：✅ 已移除 BOM

---

### 🔴 F-02 package.json `files` 与 .npmignore 冲突（D8）

| 验证 | 结论 |
|------|------|
| 合理性 | `package.json` files 包含 `data/`，但 `.npmignore` 排除 `data/`。npm 打包时 .npmignore 优先 → data/ 不会进入 npm 包 |
| 可实施性 | 从 .npmignore 移除 `data/` 行 |
| 收益 | `npx devcodex init` 能正确复制 violations/pending-fixes/gap-registry 模板 |

**修复**：✅ .npmignore 移除 `data/` 排除 + 清理不存在的 `tools/*` 条目 + 添加 `changelogs/` 排除

---

### 🔴 F-03 index.js init 未复制 data/ 目录（D9）

| 验证 | 结论 |
|------|------|
| 合理性 | SOURCES 只有 agents/skills/instructions/prompts，缺少 data/。init 后用户项目无 data/ 模板文件 |
| 可实施性 | 添加 `{ from: 'data', to: 'data' }` 到 SOURCES 数组 |
| 收益 | AI Agent 写入 violations/pending-fixes/gap-registry 时有正确的模板文件 |

**修复**：✅ SOURCES 数组添加 data/

---
