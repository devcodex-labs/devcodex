## 用户问题解答

### 1. 截图中 Agent 失败原因

`devcodex` Agent 显示 **"Unknown server side error occurred. Please try again."** — 这是 **GitHub Copilot 平台侧服务端错误**，与 DevCodex 代码本身无关。

**可能原因**：
- Agent 在预检查阶段尝试并行读取大量文件（Skills 34个 + Instructions 11个 + Prompts 20个），触发平台超时/资源限制
- 第三方 LLM 模型（claude-opus-4.6）的 API 调用失败

**建议**：重试即可。如持续失败，可考虑在 profile 中减少预检查加载文件数量。

### 2. 文档格式问题

**根因**：`audit-dimensions/SKILL.md` 第 165 行有多余 `？` 字符破坏表格渲染：
```
？| 1 | `CHANGELOG.md` ...
```
导致整个 D15 表格在 Markdown 渲染时显示为内联文本而非表格。

**已修复** + **新增 D21 维度**：将"Markdown 渲染格式"作为正式审查维度加入 audit-dimensions，包含 5 个检查项。
