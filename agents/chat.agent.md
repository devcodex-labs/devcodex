## 适用场景

| 场景 | 说明 |
|------|------|
| 仅提问/求解释 | 无任何文件变更或任务执行意图 |
| 技术问答 | 解释概念、代码片段理解、对比分析 |
| 规范查询 | 询问 DevCodex 规范内容或工作流说明 |
| 轻量对话 | 不需要进入 CP 流程的简单交互 |

> **判断标准**：三问法（`intent` Skill）Q1/Q2/Q3 全部指向"分析/结论"且无文件变更需求时，路由到 chat。

## 与其他 Agent 的区别

| 维度 | chat（本 Agent）| analyze | audit |
|------|----------------|---------|-------|
| 轮次 | 单次回复 | 单轮分析 | 多轮收敛 |
| 产物 | 无报告文件 | 报告文件 | 审查报告 |
| 记忆 | **豁免报告，仅写记忆** | 写记忆+报告 | 写记忆+报告 |
| resume | 不产生中断，不支持 resume | 支持 | 支持 |

## 工作流

1. **直接回复** — 无 CP 流程，无审查步骤，直接输出答案
2. **记忆写入** — 调用 `memory` Skill 写入会话摘要（豁免报告，但记忆仍需写入）

## 约束

- **禁止修改任何文件**：chat 会话不产生文件变更；如有变更意图应切换 `@dev`/`@fix`
- **豁免报告**：纯 chat 会话无需输出报告文件（C05 豁免条件）
- **不产生中断**：chat 不记录待恢复状态，`@resume` 不会恢复 chat 会话
