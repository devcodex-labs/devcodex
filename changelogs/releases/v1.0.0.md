## 📝 变更摘要

v0.0.3 全面重构：项目根骨架重建，规范文件统一中文，需求管理迁移至 `website/docs/versions/v1/1.0.0/requirements/`，版本从 v1.0.0 起。

---

## 🎯 背景说明

### 为什么需要这次变更？

v0.0.3 历经多轮迭代，目录结构混乱，规范文件中英文混用，没有统一的需求管理入口。

### 现状问题

- 规范文件（agents/skills/instructions）中英文混用
- 没有需求管理文档，开发迭代缺乏依据
- 目录结构不清晰，模块边界模糊

### 目标

- 规范文件统一中文编写
- 所有需求统一写入 `website/docs/versions/v1/1.0.0/requirements/`
- 建立清晰的目录结构和模块边界

---

## 📦 变更内容

### ✨ Added（新增）

- `package.json` v1.0.0，包名 `@vextjs/devcodex`
- `plugin.json` 插件元数据（英文描述）
- `index.js` CLI 入口（init / update / status），零依赖
- `agents/devcodex-auto.agent.md` 全自动模式 Agent（CP 门控自动通过，安全底线仍强制）
- `.mcp.json` MCP Server 占位配置
- `README.md` 中文主 README
- `CHANGELOG.md` + `changelogs/` 目录（monSQLize 格式）
- `website/` 文档站骨架（Rspress）
- `website/docs/versions/v1/1.0.0/requirements/` 需求文档目录（项目唯一需求来源）
- `.devcodex/profile/` 项目规范（01-项目信息 / 02-架构约束 / 03-代码风格）

### 🔄 Changed（变更）

- 版本号从 `0.0.3` 跳跃至 `1.0.0`（重构起点）
- v0.0.3 全部源文件归档至 `v0.03/` 目录

### 🏗️ 架构精简（2026-04-09）

- **Instructions 与 Skills 层次明确**：Instructions（11 个）包含工作流规则摘要并自动注入；Skills（32 个）包含详细检查标准，按 `01-common` §Skill 按需读取表 路由读取
- **Agent 精简**：`devcodex.agent.md` 从 275 行工作流定义精简为索引文件（~32 行）
- **消除冗余 Skills**：移除 `fix-incident` 和 `self-fix-auto`（对应 Instruction 已完整覆盖）
- **按需读取机制**：新增 Skill 按需读取表，禁止全量读取 Skills，每个子类型仅读取 1~3 个对应 Skill
- **级联读取修复**：`routing/SKILL.md` 去链接化，阻断 21 个 Skill 级联读取

### 🗑️ Removed（移除）

- 旧根目录所有源文件（已归档到 `v0.03/`）
