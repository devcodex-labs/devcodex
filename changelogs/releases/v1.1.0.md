## 📝 变更摘要

新增 `copilot-instructions.md` 作为 always-on 入口层，让默认 Copilot 自动加载 DevCodex 规则，无需选择 `@DevCodex` Agent。Agent 文件精简（去除 Instructions 引用表），CLI 新增分发和检查逻辑。

---

## 🎯 背景说明

### 为什么需要这次变更？

DevCodex v1.0.1 以 `@DevCodex` Agent 为唯一使用入口，用户必须显式选择 Agent 才能触发规则。而 GitHub Copilot 的 `copilot-instructions.md` 和 path-specific `instructions/*.instructions.md` 机制允许规则自动注入，无需 Agent 中介。

### 现状问题

- 用户必须选择 `@DevCodex` 才能触发规则，默认 Copilot 不自动加载
- Agent 文件中 11 条 Instructions 引用表与 `applyTo: "**"` 自动注入重复，浪费 Token
- 不同 IDE 对 custom agent 的支持程度不同（Xcode/Eclipse 不支持 agents）

### 目标

- 默认 Copilot 打开项目时自动加载 DevCodex 规则
- 保留 `@DevCodex` / `@DevCodex Auto` 作为可选模式入口
- 覆盖更多 IDE 平台（Xcode/Eclipse 可获得基础规则）
