## Added

- 新增 `scripts/migrate-layout.js`，提供 `.devcodex` 工作区集中存储迁移的 `plan / apply / rollback` CLI。
- 新增 `scripts/test-migrate-layout.js`，补齐迁移能力的独立 smoke test。
- 新增 `data/templates/pending-issues.md`，把非阻断流程问题纳入正式模板链与分发链。

## Changed

- `.devcodex` 运行模型升级为 `workspace-namespace`：
  - 工作区级任务写入 `E:\Worker\.devcodex\workspace\...`
  - 单项目任务写入 `E:\Worker\.devcodex\<project>\...`
- `mcp/profile-server.js`、`mcp/memory-server.js`、`scripts/validate-profile.js`、`scripts/validate.js` 与相关 runtime 统一支持新布局解析。
- README / RULES / instructions / skills / website 的多客户端支持口径统一为 Copilot / Claude Code 双主支持，并补齐工作区集中存储、真实真相源和迁移后的路径语义。
- 提交与未发布边界收口：
  - 默认先写 `changelogs/unreleased.md`
  - 明确发版时再归档正式 changelog
  - 本地 `commit` 作为推荐回滚锚点，`push/tag/publish` 继续显式决策

## Fixed

- 修复 bootstrap 阶段对 `shell_command` 只读命令的误拦，并补上组合命令绕过封堵。
- 修复 audit 元循环、`pending-issues` 问题池、用户面真相源与 `<agent>` 枚举的多处单源漂移。
- 修复 `validate.js` 的治理盲区，新增对客户端叙事、模板链与独立评估规则的语义探针。
- 修复真实工作区迁移后 `validate-profile.js` / `validate.js` 仍依赖旧 repo-local `.devcodex` 的兼容问题。
- 修复 `skills/cp-gate` 与部分历史 changelog 的旧 `.devcodex` 相对引用，避免迁移后断链。

## Impact

- DevCodex 现在正式支持工作区集中存储和真实工作区迁移，不再依赖每个项目根目录下的 `.devcodex`。
- 规范、模板、MCP、Hook、校验链与部署副本已经对齐到同一套工作区命名空间模型。
- 迁移后的真实 `E:\Worker` 工作区已完成 apply，并通过全量验证闭环。

## Breaking Changes

无 API 破坏性变更；但对启用 `workspace-namespace` 的工作区来说，`.devcodex` 的正式真相源已从项目根切换到工作区命名空间。
