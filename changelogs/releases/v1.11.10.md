# v1.11.10 — config.local 连接配置唯一入口收口

> 发布日期：2026-06-02

## 变更摘要

- 收窄 S02 安全底线：禁止秘密进入可提交 / 可传播产物；用户明确授权时，明文秘密可写入已被 `.gitignore` 排除的 `profile/config.local.json` 本地 overlay。
- 新增连接配置唯一入口规则：脚本、测试、数据库 / SSH / MongoDB / 数据操作连接信息必须从当前 Profile 路径模型下的 `config.local.json` 读取；缺失时提醒用户补齐，不得自行发明 `.env` 文件、环境变量名或并行配置格式。
- 同步 dev/fix 工作流、Profile 加载、CP gate、技术方案/实施计划模板、Profile 模板、README、website 与 bootstrap 生成器，避免提示词消费者继续输出旧策略。
- 更新 `validate-profile` schema：允许 `password`、`token`、`apiKey`、`privateKey`、`clientSecret`、`signingKey`、`connectionPassword` 等已授权本地明文字段，并保留类型、`.gitignore` 与 reserved key 校验。
- 更新治理探针与回归测试：新增 `validRawSecretLocalConfig`，将 `V40/V53` 从旧的 `*Env/secretRef` 强制断言迁移到 `config.local` 唯一入口与本地明文授权断言。
