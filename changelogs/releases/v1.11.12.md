# v1.11.12 — 平台工程守门、轻路径与复审覆盖收口

> 发布日期：2026-06-04

## 变更摘要

- 新增平台工程前置守门：dev/fix 的需求或问题定义必须先判断消费者范围、共享契约边界、模块职责、维护成本与非目标，避免把“通用性/模块化”写成无消费者的空心抽象。
- 新增 `SimpleTaskFastPath`：非常明确、预计 <=2 文件、无公共契约/配置/发布/控制面/台账来源/高风险、无需多轮跟踪的简单 dev/fix 任务，可免建完整需求/bug 目录，用内联 CP 摘要、报告和记忆记录 `N/A + skipReason`。
- 新增 `ContextHandoffCard`：跨会话、跨 Agent、多批次、summary/compact 前或用户要求传递上下文时，报告或 daily tasks 必须写入 source-of-truth、confirmed decisions、open risks、next action、must-not-overwrite、validation state 与 artifact links。
- 新增 `ReviewCoverageDelta`：audit / review / ECR 的连续零发现必须说明 `ReviewedSet`、`UnreviewedRelatedSet`、`NewlyReadThisRound`、`RepeatReadReason` 与 `NoNewSurfaceReason`；无新增覆盖且无证据化理由时，不计入有效零发现。
- 补强发布与验证卫生：新增 `PackageBoundarySerialCheck`、`ConsumerDependencyTreeProbe`、发布型 Profile `PFresh-6` 与文档阅读顺序同步规则，要求 pack / boundary 检查在构建完成后单独串行执行，消费者验证失败时先排除依赖树漂移。
- 补强 active-root Profile freshness：`validate-profile.js` 新增 S02 旧口径探针，防止运行时 Profile 残留“默认禁止硬编码/秘密”表述。
- 修复发布态 changelog 校验：`V54~V57` 与 `test-spec-governance` 现在按 `unreleased + changelogs/releases/*.md` 查找证据，避免正式归档后因 `unreleased` 复位为空模板而误报。

## Changed

- 同步 `instructions.md`、`10-dev`、`11-fix`、`12-audit`、`13-analyze`、`15-memory`、`16-report`、`17-compliance` 与相关 Skills / Prompts。
- 同步 README、website development / release guide、flowcharts 与 workflow execution flow。
- 新增 `V56` 与 `V57` governance probes，覆盖平台工程前置、包边界串行、依赖树优先、导航顺序同步和复审覆盖增量。
- `V54~V57` changelog evidence 改为扫描 `changelogs/unreleased.md` 和所有 `changelogs/releases/*.md`，兼容正式发布归档状态。
- `test-requirement-artifacts` 支持识别 `SimpleTaskFastPath` 的合法 N/A 产物。
- `website/package-lock.json` 刷新 `@rspress/core` 间接依赖的 `react-router-dom` / `react-router` 到 `7.16.0`，解除发布前生产依赖审计中的 React Router 安全公告阻断。

## Fixed

- 修复简单任务被强制创建完整需求概况和实施计划的流程过重问题。
- 修复上下文传递规则只定义恢复、不定义交接产物的问题。
- 修复复审收敛可能机械重复同一批已读内容、缺少新增覆盖证据的问题。
- 修复 active-root Profile S02 旧口径无法被 `validate` 发现的盲区。
- 修复 release 归档后 `unreleased.md` 已清空但 V57 / targeted probe 仍硬要求其保留条目的误报。
- 修复 README / Profile 未区分 CLI Node >=18 与文档站 Rspress 2 维护构建 Node 20.19+ 的 Profile Freshness 风险。

## Release Gate Evidence

- `OfficialDocsEvidence`: updated。发布前审计发现 `website` 生产依赖命中 React Router 官方安全公告；已核对 React Router changelog、GitHub Security Advisory 与 npm 元数据，采用 `npm --prefix website audit fix` 将间接依赖提升到 `react-router-dom@7.16.0` / `react-router@7.16.0`。
- `ProfileImpactCheck`: updated。发布版本、当前阶段、发布型 Profile 字段与文档站 Node 维护构建下限已同步 active-root Profile；source release metadata 已同步 package / plugin / lockfile / RULES / instructions frontmatter。
- `ReviewCoverageDelta`: 本轮发布前复审按差异文件、发布元数据、active-root Profile、运行时台账、ignored host copies、部署副本和 registry/tag 事实分层新增阅读；结果写入发布报告。
- 已知非阻断项：`PI-019 / PI-020 / ISSUE-027` 属 v2 一期架构规划与技术方案包延期项，不影响 v1.11.12 package 行为与发布边界。
