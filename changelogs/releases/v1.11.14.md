# v1.11.14 — ExistingRequirementArtifactOverride 与需求回写收口

> 发布日期：2026-06-05
> 发布恢复说明：v1.11.13 source commit/tag 已推送，但 registry 未发布；本版本以新 patch 替代，不重写或删除已推送 tag。

## 变更摘要

- 修复 `PF-033 / ISSUE-035`：新增 `ExistingRequirementArtifactOverride`，明确 SimpleTaskFastPath 只豁免**新建**完整需求/bug 产物，不豁免**更新已有**需求/bug 真相源。
- 吸纳 `PI-034`：当用户调整/修改/补充既有需求或问题，且已有 `01-需求概述.md`、bug CP 产物、Profile 声明的正式需求文件或 website requirement 时，AI 必须先增量编辑对应文件，回复只做摘要。
- 将该覆盖规则同步到 `instructions.md`、dev/fix split instructions、`02-output-paths`、`cp-gate`、`requirement.prompt.md`、`implementation-plan.prompt.md`、README、website guide 与 V41/targeted governance probes。
- 延续 v1.11.13 的 `ImplementationComplexityPreference` 与 Profile auto alias 变更，发布版本改为 v1.11.14 以避免改写已推送 tag。

## Fixed

- 修复简单任务轻路径可能被误读为“已有需求文件也可只在回复中调整”的问题，避免需求真相源漂移、跨会话恢复失真和复审无法追溯。
- 修复 V41 / targeted governance probes 未覆盖“既有需求/bug 真相源必须回写”的检测盲区。
