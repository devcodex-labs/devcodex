# v1.11.15 — 问答证据门禁、复杂度用户面与产物生命周期收口

> 发布日期：2026-06-09

## 变更摘要

- 新增 `QuestionEvidenceGate / ComparativeResearchGate`：推荐、选型、同类产品/项目判断和高影响建议必须先说明证据范围；纯解释、低风险本地事实或用户明确要求快速答复时可标 `N/A + skipReason`。
- 将 CP1 复杂度主口径升级为 `ImplementationComplexityLevel`，用户面使用 `简单够用 / 中等 / 企业级` 三档；需求不详细时默认 `简单够用`，更复杂方案只能作为可选项展示。
- 新增并同步 `ArtifactDecisionMatrix / ArtifactLifecycleState`，统一需求、技术方案、实施计划、进度、目标文档、报告与记忆的 `create / update / skip / N/A` 判定优先级。
- 修正模板漂移：`technical-design.prompt.md`、`implementation-plan.prompt.md`、`implementation-progress.prompt.md` 等模板不再表达“始终创建技术方案/实施计划”的过宽要求。
- 扩展 V8 部署同步探针：从父级部署体扩展到源仓根被 `.gitignore` 忽略的本地 `AGENTS.md`、`CLAUDE.md`、`.github`、`.claude`、`.agents`、`.codex` 副本，避免本地宿主入口残留旧规范。

## Fixed

- 修复“简单任务轻路径”与“已有真相源回写”之后，模板层仍可能诱导始终创建或禁止跳过产物的问题。
- 修复推荐类问答缺少证据深度声明，导致普通解释和高影响选型容易混用同一回答策略的问题。
- 修复 V41 / `test-spec-governance` 对 `ArtifactDecisionMatrix` 正向探针和旧口径负向探针覆盖不足的问题。
