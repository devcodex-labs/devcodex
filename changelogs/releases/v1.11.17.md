# v1.11.17 — 并发策略、默认 Auto 别名与泄漏稳定性测试路线收口

> 发布日期：2026-06-11

## 变更摘要

- 新增 `extensions.devcodex.concurrency` Profile schema 与 `ConcurrencyPolicy` 规则口径：默认 `auto` 支持只读准备、只读子 Agent 分析和隔离验证并行；`serial` 可退回全串行；核心单写者域固定保护 `active-root`、`memory`、`report`、`ledger`、`audit-session`、`cp-state`、`source-mutation`、`package-boundary` 与 `dangerous-operation`。
- 阻断并行 mutation 误配置：项目只能追加更保守的 `locks.additionalSingleWriterScopes`，不得删除核心域；首期不支持 `parallel` 模式、`allowParallelMutations` 或任何并行 mutation 配置。
- 将 `@rocky` 从项目 Profile 示例别名升级为 Auto v1.1 全局默认精确别名；`extensions.devcodex.autoAliases` 改为替换默认别名的配置项，省略沿用默认，空数组关闭默认别名。
- 新增项目工程审查 `PE-12 资源生命周期与泄漏风险`：代码审查必须检查内存泄露、资源泄漏、监听器/定时器/连接/流未释放、缓存无界增长、前端组件卸载清理缺失等问题；不适用时写明 `N/A + skipReason`。
- 新增测试路线 `LeakRiskStabilityPressureTest`：写测试用例或回归验证时按项目资源生命周期风险判定是否纳入泄漏风险稳定性压测；命中长运行、高并发、缓存/连接/监听器/定时器/流/socket/worker/订阅/组件生命周期或 `PE-12` 风险时，TestRoute/场景测试必须记录基线、压力过程、冷却后回落、资源指标前后对比和清理证据。
- 补齐活动版本 `1.0.1` P1 需求页与站点入口：新增 `leak-risk-stability-pressure` 详情页，同步 requirements index、版本 changelog 与 Rspress sidebar；将 `concurrency-policy` 详情页状态更新为已实现。

## Fixed

- 修复测试规范只覆盖功能正确性、未明确把泄漏风险稳定性压测纳入 TestRoute 判定的缺口。
- 修复代码审查规范缺少显式内存泄露 / 资源泄漏检查维度的问题。
- 修复 `@rocky` 仅作为项目 Profile 示例而未成为 Auto 全局默认别名，导致同一自然语言授权在新项目中不可预测的问题。
- 修复 `ConcurrencyPolicy` 缺少 Profile schema、active Profile 说明和非法配置探针的问题。
- 修复活动版本 changelog 已记录 `LeakRiskStabilityPressureTest`，但 requirements index、P1 详情页和 website sidebar 不完整的问题。
