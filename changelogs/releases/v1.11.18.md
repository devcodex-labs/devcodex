# v1.11.18 — 前端体验质量门禁与跨项目吸纳守门收口

> 发布日期：2026-06-11

## 变更摘要

- 新增 `FrontendExperienceQualityGate`：前端页面、组件、控制台、官网、文档站、可视化工具或游戏任务，必须按项目现实判定 UI / 交互体验质量门禁。
- UI 视觉组覆盖 `FrontendDesignSourceGate`、`UIFidelityGate`、`StyleThemeConsistencyGate`、`ResponsiveStateCoverageGate` 与 `VisualVerificationGate`。
- UX 交互组覆盖 `InteractionFlowGate`、`InteractionFeedbackGate`、`InputModalityAccessibilityGate`、`ErrorPreventionRecoveryGate` 与 `MotionTransitionUsabilityGate`。
- 新增 `CrossProjectLearnedGuards`，吸纳 `data/` 目录中经复核值得沉淀的八项守门：`CodeTruthRequirementGate`、`ManualReviewEvidenceRetention`、`DocumentationTranslationParityGuard`、`FormalDocsDevCodexBoundary`、`LLMPromptContractTriage`、`VerificationScopeBudgetGate`、`LiveVerificationExecutionObligation`、`AdapterBenchmarkAttribution`。
- 同步 dev/fix/audit/test Skill、CP1/CP2/CP3 模板、开发/修复/审查/场景测试报告模板、README、website guide、活动版本 P1 需求页、Rspress sidebar 与部署副本。
- 新增 `V61` validate 探针和 `test-spec-governance` targeted probe，防止前端体验门禁和跨项目吸纳守门在后续规范源、模板、文档站或部署副本中漂移。

## Fixed

- 修复前端任务只检查功能正确性、未要求 UI 还原度、风格主题、响应式状态和交互体验证据的规范缺口。
- 修复人工复核、视觉检查、手工冒烟或外部页面观察可被一句“人工检查通过”替代的问题。
- 修复“已接入 / 已支持 / 已验证 / 可运行 / 可发布”类声明缺少代码真相源和真实执行证据的风险。
- 修复多语言文档、正式文档、prompt/Hook/MCP 契约、验证范围预算和 adapter/provider benchmark 归因缺少统一触发口径的问题。
- 修复 GitHub Packages 发布链中 `npm publish --dry-run` / `prepublishOnly` 继承 GitHub Packages registry 后导致 `npm audit` 命中非审计端点的问题；`test:audit` 现在显式使用 npm 官方审计 registry。
