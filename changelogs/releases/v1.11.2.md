# v1.11.2 — 治理生命周期与运行态落点收口

> 发布日期：2026-05-28

## Highlights

- 治理生命周期收口：新增 `spec-governance` Skill，明确 RecordRouter 意图驱动记录分流与 SCV 规范变更验证链。
- workspace-namespace 运行态落点修复：CLI/Profile/Hook 状态目录、Codex adapter 备份与临时/备份产物统一落到 active-root。
- 发布防漂移增强：补齐 release/profile/audit-state 相关 validate 探针，降低发版后口径漂移风险。

## Changed

- 新增 `spec-governance` Skill，规范 `record.violation`、`record.spec-defect`、`record.process-improvement`、`record.pending-issue`、`record.audit-gap` 等记录意图的分流边界。
- 为规范源、Skill、Hook、CLI、MCP、模板、部署副本、路径规则与 validate 语义变更补充 SCV-0~SCV-7 验证要求。
- active-root Profile 改为全模式 PC0~PC7 入口检查口径，历史归档页不再维护固定 Skill 数量，并将旧 prod 预检查规则标注为历史阶段规则。
- 延续并复验 ECR、Intent Expansion Card、ConfirmationRequest 与推荐结论防回归语义，确保本补丁发布后闭环规则仍可由 validate 探针覆盖。

## Fixed

- 修复 workspace-namespace 下 CLI/Profile/Hook 状态目录、Codex adapter 备份目录和项目内 `.devcodex/.tmp` 的落点漂移。
- 修复 MCP SUMMARY 新建模板与 Profile scripts 资产清单口径不一致的问题。
- 清理已发布 `changelogs/unreleased.md` 残留，并增强 validate 对 release/profile/audit-state 漂移的防回归检查。
