# v1.11.20 — 最新 data 吸纳守门补强

> 发布日期：2026-06-12  
> 变更类型：规范治理 / 文档站 / 测试门禁  
> 风险级别：P1  
> 向后兼容：✅ 兼容

## 变更摘要

本版本吸纳最新仍需吸纳清单，将全工作区 data 扫描、遗漏专审、文档站视觉验收、方法级泄漏压测和 v2 正式方案包转为可执行门禁，并补齐 V63 探针。

## Added

- 新增 `WorkspaceDataAbsorptionScopeGate`：data 吸纳必须扫描 `.devcodex/*/data/` 全命名空间。
- 新增 `FlowchartNodeExplanationGate`：正式流程图和 Nxx 节点图必须配套中文节点说明。
- 新增 `DocsSiteVisualAcceptanceGate`：文档站/官网视觉验收覆盖主题、点击、动效、代码 token、TOC 和辅助导航。
- 新增 `OmissionOnlyReviewGate`：用户要求遗漏专审时只列此前未覆盖且仍有价值的项。
- 新增 `MethodLevelLeakPressureProbe`：高风险资源泄漏修复需评估公开方法级重复调用或生命周期压测。
- 新增 `V2FormalSolutionPackage`：建立 v2 一期正式 CP1/CP2 方案包与 website formal page。
- 新增 `V63` validate 探针和 `test-spec-governance` 覆盖。

## Changed

- 同步 `instructions.md`、`10-dev`、`12-audit`、dev/audit/test/doc Skill、CP/report prompts、README、website guide、requirements index、sidebar 和 v2 路线图。
- 同步工作区 `.github/`、`.claude/`、`AGENTS.md`、`.agents/` 与 `.codex/` 部署副本。
