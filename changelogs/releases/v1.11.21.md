# v1.11.21 — 审查发现 intake 分流门禁

> 发布日期：2026-06-17  
> 变更类型：规范治理 / 审查分流 / 测试门禁  
> 风险级别：P1  
> 向后兼容：✅ 兼容

## 变更摘要

本版本吸纳 `PF-054 / PI-051`，新增 `ReviewFindingIntakeGate` / `DesignIntentAndDocsConsistencyGate`，把外部审查报告、AI review finding、audit issue 和代码评审发现进入 analyze/audit/fix 前的分流流程固化为可执行门禁，并补齐 V64 探针。

## Added

- 新增 `ReviewFindingIntakeGate`：审查发现进入修复前必须先分类为 `must-fix`、`user-decision-required`、`docs-implementation-drift`、`test-coverage-gap`、`already-fixed-or-not-reproduced` 或 `intentional-design-accepted`。
- 新增 `DesignIntentAndDocsConsistencyGate`：对兼容设计、产品取舍、文档/实现漂移和测试覆盖缺口做明确归因，避免把“需用户决策”或“只需补测试/文档”的事项误修成 runtime bug。
- 新增 5 个子探针：`AuditReportIsSignalNotEvidence`、`IntentionalDesignClassification`、`UserDecisionBeforeMutation`、`DocsImplementationDriftAttribution`、`TestCoverageGapOnly`。
- 新增 `V64` validate 探针和 `test-spec-governance` 覆盖。

## Changed

- 同步 `instructions.md`、dev/fix/audit/analyze instructions、audit/analyze/fix/dev/report/test/document-sync Skill、CP/report prompts、README、website guide、活动版本 changelog 与 Profile。
- 同步工作区 `.github/`、`.claude/`、`AGENTS.md`、`.agents/` 与 `.codex/` 部署副本。
- `PF-054` 已关闭，`PI-051` 已标记已吸纳。
- 发布前审计修复 website 锁文件：`@rspress/core` 更新到 2.0.14，`dompurify` 更新到 3.4.10，`npm --prefix website audit --omit=dev` 归零。
