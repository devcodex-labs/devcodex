# v1.11.22 — 高保真 UI / 提交授权 / 兼容契约吸纳门禁

> 发布日期：2026-06-17  
> 变更类型：规范治理 / 前端体验 / 发布边界  
> 风险级别：P1  
> 向后兼容：✅ 兼容

## 变更摘要

本版本吸纳最新复审确认的 V65 守门清单，将 Figma/截图高保真还原、局部视觉范围冻结、真实 preview 与状态回归、生产设计资产预算、运行时 i18n 验证、显式 commit 授权、兼容契约权威、UI 真相源冲突、公开文档发布版本边界、集合关系命名和用户可见验证产物语言统一升级为可执行门禁。

## Added

- 新增 `FigmaHighFidelityRestorationGate`、`ScopedVisualChangeGate`、`InstalledPluginVisualVerificationGate`、`ActualPreviewChainAndMockFallbackGate`、`UIStateScopeRegressionGate`、`FigmaProductionAssetBudgetGate` 与 `RuntimeI18nArtifactVerificationGate`。
- 新增 `ExplicitCommitAuthorizationGate`：实际本地 `git commit` 必须有用户当前会话明确授权。
- 新增 `CompatibilityAndContractAuthorityGate`：兼容修复必须区分零代码消费者兼容、上游合同权威和官方 public API 证据。
- 新增 `UIConfirmedSourceConflictTraceGate`、`PublicDocsReleasedVersionGate`、`CollectionRelationIdNamingGate` 与 `UserFacingVerificationArtifactLanguageGate`。
- 新增 `V65` validate 探针和 `test-spec-governance` 覆盖。

## Changed

- 同步 `instructions.md`、dev/fix/audit/analyze instructions、`test-router`、dev/audit/report/document-sync/api-verification Skill、CP/report prompts、README、website guide 与活动版本需求页。
- 收紧 `commit` 规则：回滚点或语义批次清晰只允许作为建议提交或请求确认理由，不能自动提交。
- 同步工作区 `.github/`、`.claude/`、`AGENTS.md`、`.agents/` 与 `.codex/` 部署副本。
- Profile 更新为 v1.11.22 发布准备态，并纳入 V65 当前焦点。
