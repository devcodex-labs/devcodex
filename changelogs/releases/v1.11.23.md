# v1.11.23 — 复审文档体验 / 公开用户文档 / 最终汇报吸纳门禁

> 发布日期：2026-06-23  
> 变更类型：规范治理 / 文档体验 / 发布边界  
> 风险级别：P1  
> 向后兼容：✅ 兼容

## 变更摘要

本版本归档 V66/V67 两批跨项目吸纳守门，将复审维度增量、用户视角文档、文档消费者扫描、产物链接去重、前端真实预览运行时探针、公开用户文档维护边界和最终回复 active 范围升级为可执行门禁。

## Added

- 新增 `ReviewDimensionDeltaGate`：复审连续零发现时必须证明审查维度有增量，避免机械重复同一检查面。
- 新增 `UserPerspectiveDocsGate`：正式用户文档需从使用者角度检查详细度、首次成功路径、字段/参数/状态/错误解释、排错恢复与心智负担。
- 新增 `DocsConsumerSweep`：文档变更需扫描 README、website、Profile、示例、模板、导航和代码消费点。
- 新增 `ArtifactLinkSetDedupeGate`：产物链接按 canonical path 去重，避免同一文件在用户界面中双份展示。
- 新增 `FrontendRuntimeNetworkProbeGate`：真实前端预览需检查 console、network、资源 404、API target、hydration/runtime error 等证据。
- 新增 `PublicUserDocsMaintainerBoundaryGate`：公开用户文档、README、官网教程、快速上手、配置/扩展/框架接入指南不得把维护者验收、发布 checklist、内部同步清单、台账状态或实现者复审任务混入用户主路径。
- 新增 `ActiveRequirementFinalResponseGate`：同日或同工作区存在多个相邻需求、backlog、open 任务或未完成候选时，最终回复和完成报告必须声明当前 active requirement/task/bug id，并只围绕当前 active 范围输出完成状态、验证证据、dirty 边界和默认下一步。
- 新增 V66/V67 validate 探针与 `test-spec-governance` 覆盖，关联 `PI-052 / PF-056 / PI-053 / PI-054 / PF-057 / PF-058`。
