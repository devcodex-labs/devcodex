## 变更摘要

本版本归档 v1.11.26 之后的 V71~V74 治理能力：把“通用规范继续堆叠”的吸纳方式升级为 Skill-first 与分层吸纳架构，补齐用户确认的半覆盖 / 未完整吸纳门禁，新增自我进化治理 Skill，并为历史通用规范分层迁移、prompt/report 长清单和旧吸纳项建立逐文件矩阵迁移机制。

## 新增 / 强化 Skill

- 新增 `user-manual-authoring`：承接站点文档、最终用户使用文档、README、quick start、接入手册和 docs-first 用户手册。
- 新增 `review-checklist`：承接正式复审、ECR、发布前复审、多轮收敛和 finding 批次的清单冻结、证据执行和状态新鲜度。
- 新增 `evolution-governance`：承接自我进化、自动吸纳、模型辅助规范优化、自动补 Skill / Prompt / Probe 和自动治理候选的控制面。
