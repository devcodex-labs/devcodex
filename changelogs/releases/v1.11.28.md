## 变更摘要

本版本归档 v1.11.27 之后的 V75~V78 治理能力：把默认分析工作流下沉到独立 `analyze-default` Skill，补齐 `SpecRadarSubgate` 与 `GovernanceGateRegistry` 作为门禁分组索引，新增 Prompt / Report 长清单防回流探针、复审逃逸记录门禁、release / pack / install smoke 的原生命令真实退出码防假阳性门禁，并补齐确认后复审分级、开发偏移防护、验证计划物化、用户建议采纳根因说明和文档 IA / 中文主表达探针。

## Skill 与执行链调整

- 新增 `analyze-default` Skill，承接默认只读多轮分析、代码事实优先、analyze-lite 关联联查与 PCV 收敛验证。
- `spec-governance` 新增 `GovernanceGateRegistry`，统一为 PC4、技术方案、实施计划、报告模板和 validate 探针提供 `gateGroup / ownerSkill / validationRoute` 索引。
- `review-checklist` 新增 `ReviewEscapeRecordGate`，复审或实施中发现清单遗漏时必须记录 `escapedItem / whyMissed / missingDimensionOrProbe / prevention / checklistPatch / rerunEvidence / ledgerRoute`。
- `release-verification` 新增 `NativeCommandExitCodeGate`，要求 pack/publish/install smoke、CLI replay 和 curl/git/npm/node/PowerShell/Bash wrapper 记录真实 `command / shell / cwd / exitCode / auth-config source`，不得用成功文案替代原生命令退出码。
- `cp-gate` / `review-checklist` / `dev-plan-review` 新增 `PostConfirmationReviewScopeGate`，CP 确认后按风险判定轻量复审或全面复审，高风险场景必须使用冻结清单和 PR-2~PR-7 证据。
- `dev-default` / `execution-contract` 新增 `DevelopmentDriftGate`，进入编码前和实施中核对 `allowedFirstBatch / blockedScope / driftTriggers / validationRoute`，范围偏移时回到 CP2/CP3。
- `dev-plan-review` 新增 `VerificationPlanMaterializationProbe`，技术方案必须把验证计划、验收标准和退出条件物化为可 grep 证据。
- `spec-governance` / `report` 新增 `AcceptedSuggestionRootCauseGate`，采纳用户纠正时必须说明 whyMissed、采纳依据、台账编号和防复发动作。
- `user-manual-authoring` / `dev-docs` / `document-sync` 新增中文主表达和 sidebar IA 探针，要求用户文档 page role 与 sidebar group 语义可验证。

## 验证与探针

- 新增 V75 `PromptLongGateListDriftProbe`，用 SCV 负向样例防止旧版 `CrossProjectLearnedGuards`、`LatestAbsorptionGuards` 或 `ConfirmedAbsorptionCompletenessGates` 长清单回流到 README、website、instructions 或 prompts。
- 新增 V76 `ReviewEscapeRecordGate` 同步探针，反查 review-checklist、spec-governance、test-router、report、prompts、README、website 与 changelog。
- 新增 V77 `NativeCommandExitCodeGate` 同步探针，包含 native command 失败但脚本仍打印 OK 的负向样例，以及 `$LASTEXITCODE` / strict shell / wrapper 正向样例。
- 新增 V78 `PostConfirmationReviewScopeGate` / `DevelopmentDriftGate` / `VerificationPlanMaterializationProbe` / `AcceptedSuggestionRootCauseGate` / `ChinesePrimaryExpressionGate` / sidebar IA 同步探针，反查 Skill、Prompt、README、website 与 changelog。
