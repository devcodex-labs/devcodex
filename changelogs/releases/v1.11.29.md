## 变更摘要

本版本吸纳工作区 data 台账中仍有泛化价值的测试与运行时验证缺口：coverage 必须独立判定，不能用测试断言通过替代；外部 runtime、plugin、registry、adapter、provider、injected runtime 与 owner mutation 需要生命周期矩阵；function source / hash / toString / fingerprint 参与 key、checkpoint、幂等或去重时需要误判矩阵；同一风险簇连续返修需要先升级风险模型，再按 targeted / related suite / full gate 分层验证。
