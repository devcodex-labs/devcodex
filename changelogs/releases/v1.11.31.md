## 变更摘要

本版本收口两批治理能力：A1~A10 `LatestAbsorptionExecutionPack` 将最新可吸纳项按分层吸纳架构落到 Skill、Prompt、执行消费者、探针、公开文档与部署副本；Profile 三档闭环将项目 Profile 标准拆为 `profile-lite`、`profile-standard`、`profile-closed-loop`，并新增全 `.devcodex` Profile 校验脚本。

## 新增能力

- 新增 A1~A10 `LatestAbsorptionExecutionPack`，覆盖配置 canonical namespace、Profile runtime contract、行为语义与负向翻译、示例真相面、callback 示例范围、派生消费者、失败注入、功能清单证据矩阵和多批次进度状态。
- 新增 V82 探针，反查 A1~A10 是否同步到 Skill、Prompt、TestRoute、report、README、website、changelog、Profile、部署副本和来源台账回写。
- 新增 `ProfileTierStandardGate`、`ProfileLifecycleClassificationGate` 与 `AllDevCodexProfileValidationGate`，明确 `conditional-required` 是文件级触发规则，不是项目档位。
- 新增 `scripts/validate-all-profiles.js`，用于扫描 `.devcodex/workspace/profile` 与 `.devcodex/<project>/profile`，汇总 error / warning 并支持 strict warning 模式。
- `devcodex-v1` active Profile 升级为 `profile-closed-loop` 示例，补齐 `06-功能清单.md` 与 `07-用户文档与契约规范.md`。

## Skill 与执行链调整

- `load-profile` 与 `profile-bootstrap` 同步三档 Profile 标准、文件生命周期和全项目 Profile 校验触发条件。
- `test-router` 与 `report` 同步 `ProfileTierValidation / AllDevCodexProfileValidation` 证据要求。
- `spec-absorption`、`spec-governance`、文档审查、测试、复审清单和用户文档相关 Skill 同步 A1~A10 执行包的 gate 分组与报告字段。
- `prompts/technical-design.prompt.md`、`implementation-plan.prompt.md`、`implementation-progress.prompt.md` 与 report prompts 同步最新吸纳执行包和验证证据口径。

## 公开文档与 Profile

- README 新增 Profile 三档闭环校验说明和 `validate-all-profiles` 命令。
- website development guide 同步 Profile 三档标准与全工作区校验说明。
- `changelogs/unreleased.md` 增加 Profile 三档与全项目校验的发布前提示，归档后重置为空未发布池。
- active Profile 的当前焦点、功能清单、用户文档与契约规范已同步到最新发布口径。

## 兼容性

- 不改变 CLI 命令、Hook 入口、包公开 API、安装方式或既有 Skill 触发语义。
- 历史项目 Profile 未声明档位时默认按 `profile-lite` 兼容处理，并输出 warning；默认全项目校验不因历史 warning 阻断。
- `--strict-warnings` 可用于后续治理批次，把历史 warning 升级为失败信号。
