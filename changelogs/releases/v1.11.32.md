## 变更摘要

本版本收口专家型产物质量、17 个专家 Owner Skill、记忆启动链真相源与发布包公开脚本依赖闭包四类能力。DevCodex 现在能把“代码 / 文档 / 示例 / 技术方案 / 报告要有资深专家水准”拆解为可触发、可验证、可报告的 Skill 和 Gate；同时新增 V86，防止宿主 Memories 或模型长期偏好替代 Profile、tasks、reports 和源码 / 文档真相源读取；发布验证新增 `PackagedScriptDependencyClosureGate`，防止源码测试通过但 tarball 缺少公开脚本运行时依赖。

## 新增能力

- 新增 `expert-output-quality` Skill，固化 `ExpertOutputQualityGate`、`ProductionRecommendedPathGate`、`FrameworkNativeCapabilityFirstGate`、`FixtureBoundaryDisclosureGate`、`AntiPatternContrastGate` 与 `ExpertEvidenceMatrixGate`。
- 新增 17 个专家 Owner Skill：`product-strategy`、`developer-experience-architecture`、`ux-interaction-architecture`、`frontend-architecture`、`backend-domain-architecture`、`production-readiness-sre`、`api-contract-architecture`、`external-integration-architecture`、`platform-ecosystem-architecture`、`ai-agent-system-architecture`、`data-architecture`、`security-threat-modeling`、`quality-strategy`、`design-system-architecture`、`accessibility-i18n`、`growth-analytics`、`business-model-review`。
- 新增 `MemoryCannotSatisfyBootstrapGate`，要求 Codex / 宿主 Memories、模型长期偏好、SUMMARY 或 ContextHandoffCard 只能作为 `navigation-hint`，不能替代 bootstrap、Profile 加载、Context Rehydration、CP 确认、报告结论或验证证据。
- 新增 `PackagedScriptDependencyClosureGate`，要求发布包中公开的 `scripts/*.js`、CLI helper、Profile validator、migration tool 或公开验证脚本递归核对本地 `require()`、`path.join(ROOT,'scripts',...)`、spawn 目标脚本和等价运行时依赖都进入 tarball。
- 新增 V84 / V85 / V86 探针，分别覆盖专家型产物质量、专家 Owner Skill 和记忆启动链真相源。

## Skill 与执行链调整

- `dev-plan-review`、`dev-docs`、`audit-*`、`test-router`、`report`、Prompt 模板、README、website、Profile 和部署副本同步专家型产物质量证据字段。
- `routing`、`spec-governance`、`spec-absorption`、`test-router`、`report`、技术方案 / 实施计划 / 报告 Prompt 同步 `ExpertOwnerSkillGate` 与 17 个 ownerSkill 字段。
- `load-profile` 与 `memory` 同步 `MemoryCannotSatisfyBootstrapGate`，明确内置 Memories 只能提示“可能要看哪里”，真实结论仍来自 active namespace 文件真相源。
- `test-router` 与 `report` 增加 `memoryCannotSatisfyBootstrap` / `MemoryCannotSatisfyBootstrapGate` 输出字段，要求报告列出 navigation hint、已读取文件、冲突处理和 V86 证据。
- `release-verification`、`audit-release`、`test-pack-clean` 与 V6 包边界检查同步 `PackagedScriptDependencyClosureGate`；`package.json` `files` 补入 `scripts/validate-profile.js`，确保已打包的 `validate-all-profiles.js` 在临时安装包内可执行。

## 兼容性

- 不改变 CLI 命令、Hook 入口、包公开 API、安装方式或既有工作流路由。
- 新增专家 Owner Skill 是按需触发能力；`growth-analytics` 与 `business-model-review` 保持 P3 条件触发，未命中时写 `N/A + skipReason`。
- 开启宿主 Memories 不会改变 DevCodex 文件读取门槛；无法读取文件真相源时只能写阻塞或降级。
