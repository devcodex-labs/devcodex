# v1.11.5 — requirement 运行时产物结构探针补强

> 发布日期：2026-05-29

## Highlights

- requirement 运行时产物现在有了正式守门探针：`validate.js` 新增 `V41`，会检查近期 requirement 目录里的 `01-需求概述.md`、`04-实施计划.md`、`05-实施进度.md` 是否保持最低结构。
- 新增 targeted test `scripts/test-requirement-artifacts.js`，覆盖“合格 recent requirement”“不合格 recent requirement”“历史 requirement 不纳入本轮检查”三条关键路径。
- 回补近期 requirement 样本漂移，收口“模板源已收紧、运行时产物却持续变薄”的逃逸问题。

## Changed

- `scripts/validate.js` 接入 `scripts/lib/requirement-artifact-check.js`，以 active runtime root 为准扫描近期 requirement 运行时产物。
- `package.json` 的 `test:all` 新增 `test-requirement-artifacts` 主链校验。
- 当前 requirement 样本 `治理台账状态回写与遗留项收敛` 的 `01/04/05` 已补回目录导航、计划骨架、进度元信息、验证结果、阻塞与恢复、下一步和变更记录。
- 近期 requirement 当前消费者中的计划/进度漂移已同步修补：`控制面能力模块化与发布闭环`、`规范治理生命周期与落点闭环`、`规范资产跨层漂移收敛与校验补强`、`治理台账优化清单与主动记录强制化`。
