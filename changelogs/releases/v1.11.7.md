# v1.11.7 — 官方文档证据与 Profile 联动规范补强

> 发布日期：2026-06-01

## Highlights

- 新增 `C20/C21`，把“引入依赖/框架/SDK/API 前必须读取官方文档”和“项目事实变化后必须联动 Profile”提升为强制约束。
- 建立 `OfficialDocsEvidence` 执行链，要求 CP2 / 技术方案记录官方来源、版本或日期、关键用法、限制、兼容性与降级依据。
- 建立 `ProfileImpactCheck` 执行链，要求 dev/fix 在技术栈、目录边界、脚本、测试/发布路线、配置或本地 overlay schema 变化时主动同步 Profile 或写明 `skipReason`。
- 新增 `V54` 与 targeted governance probes，覆盖 instructions、skills、prompts、README、website、changelog 与测试消费者，防止规则新增后消费者漂移。
- 发布前安装烟测发现并修复 CLI 包边界：补齐 `scripts/lib/cli-host-utils.js`、`scripts/lib/cli-runtime-utils.js`、`scripts/lib/profile-bootstrap-utils.js`，避免 pack 后运行 `devcodex status` 缺少 runtime helper。

## Changed

- `instructions.md`、`instructions/01-common.instructions.md`、`instructions/01b-record-router.instructions.md`、`instructions/10-dev.instructions.md`、`instructions/11-fix.instructions.md` 同步官方文档证据与 Profile 联动规则。
- `skills/dev-plan-review`、`skills/document-sync`、`skills/test-router`、`skills/report` 增加 `OfficialDocsEvidence` / `ProfileImpactCheck` 守门与报告要求。
- `prompts/technical-design`、`implementation-plan`、`implementation-progress`、`delivery-checklist`、`report-dev`、`report-fix` 增加对应证据字段。
- README 与 website 开发指南同步用户可见说明，明确何时需要官方证据、何时需要 Profile 联动。

## Added

- `scripts/lib/validate-governance-tail.js` 新增 `checkV54`。
- `scripts/test-spec-governance.js` 新增官方文档证据与 Profile 联动消费者探针。
- `scripts/test-pack-clean.js` 会从 `index.js` 反向收集本地 runtime require，防止 CLI 运行时依赖漏发。
- `scripts/validate-versions.js` 增加 `RULES.md` 与 `instructions/**/*.md` frontmatter 版本一致性检查。
