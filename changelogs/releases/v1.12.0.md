## 规模路由规则

项目、目录或工作区分析/审查/扫描在 broad scan 前必须先：

1. 唯一识别项目、source root、active root 和排除边界。
2. 采集 relevant file count、parseable bytes、largest file、directory concentration、derived artifact ratio、consumer fan-out。
3. 选择 `single-pass / batched / sampled+deep-read / blocked`，并记录 ScaleDecisionRecord。
4. 分批任务写 checkpoint；错误 glob、超时、派生产物污染或未解析项目的运行结果标为 invalid，不得用于完成声明。

默认只有同时满足不超过 50 个相关文件、2 MiB 可解析内容、最大文件不超过 256 KiB、消费者扇出不超过 10 且无“大目录”信号时，才允许 single-pass。Profile 可以更保守，不得放宽该边界。
