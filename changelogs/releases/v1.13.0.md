## 核心变化

- 将 `validate.js`、治理测试与 CLI 巨型入口拆为确定性 probe registry、分套件验证器、安装/维护命令 owner 和命令注册表，新增 V92/V93 控制面优化与模块化探针。
- 新增受检命令、双 registry dry-run、`ScopedRegistryResolutionGate` 与 scope override 正负向探针、Node 18/20/22 与 Windows CI 矩阵、`c8@10.1.3` report-only coverage、运行态一致性索引和 managed deployment manifest；stale 文件继续只报告、不自动删除。
- 新增 gray `rework-prevention-engineering`，用 WorkUnit/ReworkEvent、双重根因、FirstPassYield、前瞻 trial 与效果回路治理返工率；gray 不等同于默认强制触发。
- 新增 gray `consumer-validation-engineering`，冻结主仓/消费者仓身份、artifact/lock/pack、多分母状态机、跨仓 CI、新鲜度和置信度降级证据。
- 新增 `AgentCapabilityDomainCompletenessGate`、`DocsAudienceRoleAndRenderedSequenceProbe`、`ModulePerformanceCoverageAndMaintenanceGate` 及 V94/V95 正负向探针。
- 新增 `ChecklistStateMaterializationGate` 与 V94 stale snapshot 负向探针，clean/closed 声明前原子核对复审清单六区块，阻断局部回写造成的假收敛。
- 新增 gray `CandidateDiffCompletenessGate`：commit/tag/publish 前物化 staged candidate snapshot，覆盖 tracked/untracked，并用 cached diff、name-status、secret-shape 与 intended scope 对账阻断候选差异假绿；本版本复证只关闭当前事件，长期有效性仍等待后续发布 WorkUnit 前瞻证据。
- 治理记录改为意图驱动生命周期：中性候选、复合 RecordRouter、成功落盘证据、`RecordNoneChallengeGate` 与跨轮迁移共同防止关键词误触发和漏记。

## 资产与验证面

- Skill portfolio：76 个（74 active + 2 gray），依赖环 0、孤儿 0。
- 验证探针：V1~V95；覆盖 source、Prompt、TestRoute、report、Profile、plugin/portfolio、公开文档和 Copilot/Claude/Codex 部署副本。
- 发布包同时验证 package boundary、公开脚本依赖闭包、pack/install smoke、GitHub Packages dry-run、目标提交远端 CI 与发布后 registry 事实；双 registry dry-run 工具保留为未来可选能力，不代表 v1.13.0 发布到 npmjs。

## 升级

先按 README 配置 GitHub Packages registry 与 `NODE_AUTH_TOKEN`，再安装或升级：

```bash
npm install @vextjs/devcodex@1.13.0
npx @vextjs/devcodex update
```

v1.13.0 仅发布到 GitHub Packages，需要 `read:packages` 认证；本版本不提供 npmjs 匿名安装通道。
