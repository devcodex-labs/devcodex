# v1.14.0 Profile 生成、控制面契约与发布效率治理

> 发布日期：2026-07-14

## 版本信息

| 项目 | 内容 |
|---|---|
| 版本号 | v1.14.0 |
| 发布类型 | MINOR |
| 兼容性 | 向后兼容；CLI 仍支持 Node.js >=18；未改变既有 Profile 默认继承语义，新增降档必须显式授权 |
| 分发 | GitHub Packages 单渠道（restricted；安装需 `read:packages`） |

## Profile 生成与功能清单

- 新增 `ProfileGenerationContractGate`，由 `mcp/profile-contract.js` 统一三档文件集合、语义检查和功能清单 schema，CLI、加载器、状态与 validator 共同消费。
- 新增 `devcodex profile plan` 与真实 `--dry-run` 零写入预览；展示目标根、已检测/请求/推荐/目标档位和逐文件动作。
- 新增 `ProfileTierMigrationSafetyGate`：默认继承已有档位，升级只补缺失文件；隐式降档拒绝，`--allow-downgrade` 保留高档文件，`--force` 先备份。
- 新增 `FeatureInventorySchemaGate` / `FeatureInventorySchemaV1` 十字段规范表及正负验证，阻断空清单、占位行、伪来源、重复真相源和发布状态冲突。

## 控制面、返工预防与验证

- 新增 canonical workflow capability、tenant manifest/selector、Governance Gate、report 与 TestRoute JSON 契约；共享 loader 取代并行 mega-registry。
- 补强 API endpoint matrix、empty-test fail-closed、风险化场景/coverage/E2E 路由、临时项目依赖隔离与 Git 临时 index 验证。
- Skill portfolio 从明确强制读取关系生成 dependency graph，绑定结构化 triggers、冲突复核、active/gray 证据、回滚条件与确定性生成检查。
- `dev-plan-review` 同阶段聚合安全独立 blocker，并以冻结 `BlockerSnapshot`、统一修复和依赖式复验降低遗漏返工；`rework-prevention-engineering` 与 `ChecklistStateMaterializationGate` 继续由 V94 复证。
- 修复 delivery/progress/memory/analyze/docs 模板条件，补齐三轨 CHANGELOG、ContextHandoffCard、CRS/PCV 与条件 TOC；规范 Markdown 增加围栏和结构验证。

## 剩余规范吸纳

- 新增 `ReleaseEfficiencyControlGate`：`CandidateFreezeGate`、关键路径预算、验证证据复用与发布返工事件；`IsolatedConsumerCwdGate` 要求 pack/install smoke 使用显式 consumer manifest、真实 consumer cwd 与 source identity 前后对账，并以 `npm init --prefix` 为负例；无可比较基线时保持 advisory。
- 新增批次范围 diff / 新验证消费者重绑定、契约变体隔离与 mutation、阶段交付语义、场景覆盖矩阵和 durable batch orchestration 门禁。
- 扩展 gray `consumer-validation-engineering`：`DesignFitnessGate` 校验消费者主路径适配，`ValidationFindingRepairLoop` 在修复后使旧证据失效并按影响矩阵复跑。
- 新增 V96 模块化正负探针并扩展 V95；同步 canonical registry、report schema、Owner Skills、README、website、Profile、台账与三宿主部署副本。

## 验证面

- 验证探针扩展到 V1~V96，覆盖 source、Prompt、TestRoute、report、Profile、portfolio、公开文档和 Copilot/Claude Code/Codex 部署副本。
- 发布链验证 full、coverage、production audit、package boundary、pack/install smoke、目标 SHA 远端 CI、annotated tag、GitHub Packages 与 fresh registry consumer。

## 升级

先按 README 配置 GitHub Packages registry 与 `NODE_AUTH_TOKEN`，再安装或升级：

```bash
npm install @vextjs/devcodex@1.14.0
npx @vextjs/devcodex update
```

v1.14.0 仅发布到 GitHub Packages，需要 `read:packages` 认证；本版本不提供 npmjs 匿名安装通道。
