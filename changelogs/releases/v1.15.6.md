# v1.15.6

> 发布日期：2026-07-31
> 类型：Patch

## 摘要

本版本发布最新 `main` 分支上的 README 用户导航与 SkillRoute 防复发修复：README 增加目录导航，方便用户快速定位安装、更新、卸载、自动推进和工作区 Skill；同时修复 MCP source observation 在已有 stale receipt 时复用旧 receipt，导致 `skill_route commit` 在已读取 profile/memory 后仍返回 `CONTEXT_BINDING_PENDING` 的复发路径。

## 主要变更

- README 新增 `## 目录`，覆盖为什么需要、解决问题、核心特色、工作方式、适合人群、5 分钟开始、更新、卸载、生效方式、添加 Skill、原生 Skill 共存、边界和许可证等用户章节。
- `PublicReadmeContractV1` 增加目录导航锚点，防止后续 README 改版漏掉用户导航。
- `context-source-observation.cjs` 在安装 observed plan 时不再复用 `stale` / `blocked` receipt，而是重建 structured-plan receipt 后再记录 MCP source outcome。
- `test-skill-route-state` 增加 stale receipt 回归用例，覆盖已有 stale lifecycle-state + fresh observed plan + MCP source results 后 `skill_route commit` 必须恢复通过。
