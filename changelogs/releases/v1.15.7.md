# v1.15.7

> 发布日期：2026-07-31
> 类型：Patch

## 摘要

本版本发布 SkillRoute MCP 契约与 closeout/rebind 防复发修复：`skill_route` 的 MCP schema 改为按操作分支声明字段，避免客户端继续把 `contextBinding` 传给 `catalog/load_stage/status`；Context Binding 失败不再只返回裸 `CONTEXT_BINDING_PENDING/STALE`，而是返回可执行的 refresh/rebind/load_stage 恢复建议；Stop hook 的 closeout 阻断也会给出下一步 `load_stage` 参数。

## 主要变更

- `skill_route` MCP `inputSchema` 改为 per-op `oneOf`：`catalog/load_stage/status` 不接收 `contextBinding`，`commit/rebind` 必须接收 `contextBinding`。
- `REQUEST_FIELD_UNSUPPORTED` 返回 `SkillRouteRequestShapeErrorV1`，包含不支持字段、允许字段和下一步建议。
- `CONTEXT_BINDING_PENDING/STALE` 返回 `SkillRouteContextRecoveryV1` 与 `nextOperation`，覆盖缺 receipt、identity mismatch、stale receipt、mandatory source 未满足等路径。
- `status` 和 Stop closeout pending 返回 `SkillRouteNextActionV1`，明确下一次应调用 `load_stage` 还是 `rebind`，并附带可直接使用的参数。
- canonical progressive Skill route schema 增加 `rebind` 操作，host capability runtime/adapter digest 同步刷新。
- 回归测试覆盖 MCP schema、请求字段负例、stale receipt 恢复、closeout pending、Stop stale rebind 和 package release 路径。
