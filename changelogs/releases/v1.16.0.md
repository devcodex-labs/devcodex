# v1.16.0

> 发布日期：2026-08-03
> 类型：Minor

## 摘要

本版本统一首次初始化、项目 Profile、用户语言与多项目运行态行为。新电脑只需在 workspace 执行 `devcodex init` 即可获得非覆盖式 Profile 基线；指定项目可用 `devcodex init --profile <项目>` 一步生成合适档位的 overlay。回复与用户产物跟随当前消息语言，派生运行态则集中到 workspace 管理的隔离分区。

## 主要变更

- `devcodex init` 自动创建缺失的 workspace `profile-lite` 基线，并保留已存在的更高档位和人工内容。
- `devcodex init --profile api` 只接受唯一存在的项目；重名时要求完整 namespace，并按项目证据选择推荐 Profile 档位。
- `devcodex update` 不再创建、升级或降级任何 Profile，`update --profile` 明确失败且不写 Profile。
- 新增 `LanguageContextV1`：当前用户消息或显式语言要求优先；回复、标题与自然语言产物正文跟随用户语言，命令、配置键、协议字段、Skill/Gate ID 与默认文件名保持稳定英文。
- 新增 workspace-aware `RuntimeStateStore`：多项目状态物理隔离，新路径优先，旧项目本地状态只读兼容，所有新写入只进入 canonical 分区。
- 新增 `devcodex runtime status` 与 `devcodex runtime prune`，可查看 owner、体积和最后使用时间；清理默认预览，`--apply` 也只删除过期的原子写入临时文件，不自动删除锁或未知状态。
- README 更新首次初始化、项目 Profile、语言一致性与运行态检查说明。

- 两项目运行态隔离、旧路径只读回退、新路径优先、禁止双写
