# v1.16.1

> 发布日期：2026-08-03
> 类型：Patch

## 摘要

本版本修复长会话中提示词随治理候选持续膨胀、不同会话继承旧候选，以及多项目 workspace 在长任务或使用项目短名时丢失目标绑定的问题。更新后，当前提示保持有界，新会话从独立治理状态开始；同一宿主会话中的项目绑定不再因固定时限失效。

## 主要变更

- 每轮只向宿主投影当前治理候选；历史未决候选压缩为固定大小摘要，避免提示词和状态文件随轮次无界增长。
- 新宿主会话不再从 workspace 或项目共享状态继承旧治理候选，旧版大状态会在首次读取时自动迁移为有界格式。
- 同一宿主会话的项目绑定持续有效，不再因任务超过 30 分钟退回 workspace 未绑定状态。
- 多项目 workspace 的自然语言项目识别与 CLI 对齐：唯一叶子名称可解析到完整 namespace，重名叶子仍保持阻断并要求完整名称。
- 增加 300 轮压力、20 会话隔离、250 条旧状态迁移、长会话绑定、唯一短名和重名短名负向测试。

## 验证

- 治理提示 300 轮压力后仍只暴露 1 个当前候选，投影不超过 1024 字符，运行态不超过 16 KiB。
- 20 个新会话相互隔离，不泄漏此前候选 ID。
- 250 条 v2 候选可迁移为 1 条当前候选和确定性历史摘要。
- Codex S15 真实宿主探针完成 ContextRead、ContextBinding、catalog、commit、条件重规划、阶段加载与 closeout。
- `npm run test:full`
- `npm run test:package-release`
- npm tarball 隔离安装与 registry 新装验证。
