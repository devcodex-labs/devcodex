# DevCodex v1.17.10

> 发布日期：2026-08-17
> 类型：Patch / 公开产品表达、README 与用户文档站

## 发布摘要

v1.17.10 将 DevCodex 的 README、npm、Plugin、CLI、GitHub 和公开文档统一到“意图驱动的 AI Coding 工作流运行时”，并把详细排错从仓库首页迁移到独立的 GitHub Pages 用户文档站。产品运行时、Hook、MCP、工作流与自动推进语义没有改变。

## 公开产品表达与合同

- 新增 `PublicProductExpressionV1` 稳定语义源，并从现有 workflow、Skill portfolio 和宿主 owner 动态生成 `PublicProductProjectionV1`。
- `PublicReadmeContractV2` 校验产品品类、六主两高级工作流、86/83/3 Skill 生命周期、六宿主状态、用户路径与跨入口 metadata；V1 仅保留一版只读兼容。
- endpoint 身份验证不再把 HTTP 200 当作充分条件，同时校验最终 URL、title、品牌标记以及 404、停放页和组织聚合页负例。
- GitHub topics 采用集合语义回读，兼容平台排序，同时保持 package/plugin keywords 的 canonical 顺序。

## README 与公开文档

- README 从 783 行收敛到 350 行，保留首次成功、工作流/Skill/宿主边界、常见任务、最短恢复路径、更新、卸载和 Workspace Skill。
- Grok ParserError/双来源、Cursor 命令碰撞与 Cloud 边界、sandbox 状态、临时目录、Memory/SkillRoute 协议等高级内容迁入公开文档。
- 新增独立、tracked、`private: true` 的 `public-site/` Rspress 站点；9 个 Markdown 页面按用户任务组织，构建同时检查 dead links 和 anchors。
- `website/` 保持维护者私有文档站，不进入公开 Git、npm 包或 Pages 发布物。

## GitHub Pages 与公开入口

- Pages 使用 GitHub Actions workflow 构建与部署，PR 只构建，main/manual 才部署；build 与 deploy 权限分离。
- `https://devcodex-labs.github.io/devcodex/` 已通过在线身份回读后，才成为 package、plugin、CLI 和 GitHub repository 的 canonical 用户入口。
- GitHub description、homepage 与 topics 使用相同产品表达并逐字段回读；`devcodex.dev` 继续只作为历史 schema identity/custom-domain candidate，不作为本版本导航入口。

## 验证与兼容性

发布资格要求 public expression/readme/docs/Profile、Rspress build/link、full/coverage/audit、Node 18/22/24/26 与 Windows 控制面、package boundary、publish dry-run、fresh tarball install/self-pack、目标提交 CI/Pages、npm/GitHub Release/provenance 和本机六宿主全部通过。

本版本不新增 root runtime dependency、产品 CLI、Hook、MCP、Rule、Skill、Prompt、后台服务、端口、自定义域名或删除动作。最终 commit、Actions run、registry tarball 摘要和本机 generation 以发布报告及 `ProfileCurrentTruthV1` 为准。
