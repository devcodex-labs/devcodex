# v1.17.7

> 发布日期：2026-08-15
> 类型：Patch / 全局运行态一致性与首次加载闭环

## 摘要

本版本关闭第二轮深审确认的 22 项问题，覆盖 ContextRead、Profile/Memory、首次 SkillRoute、catalog 首载、全局配置事务、Readiness、临时对象、命令传输、宿主证据与发布矩阵。实现保持在既有 owner 内，仅为多个真实消费者抽取有界文本读取、Memory 状态折叠、宿主命令、Readiness 与诊断作用域等小型共享模块。

## 主要修复

- Profile/Memory 正文读取必须匹配当前 active-root 的持久 `ContextReadPlanV2`；Profile section 和 Memory fallback 在源文件层分块读取，超限返回 partial/continuation，不再先全文载入。
- 未解析项目目标会持久化 `SkillRoutePendingEnvelopeV1`；PreToolUse 与 Stop 共同阻止跳过 target resolution、catalog 与 commit。
- `ProfileRouteLoadRecipeV2` 使用语义 selector 与 headroom；catalog served pages 与 ledger 双向完备，sidecar 主/备损坏和 malformed JSON 均失败关闭。
- Memory fresh index 与 fallback 共用 append-only last-event-wins 折叠；CP artifact 先完成 task-root containment、regular-file、reparse/object identity 再验证摘要。
- 全局配置解析异常不再覆盖用户内容；计划操作全量携带 CAS，rename-window 再验备份摘要；activation receipt、retained generation、status/doctor 与 `DevCodexReadinessV1` 使用同一事实投影。
- Hook 使用绝对 Node executable 与 canonical argv 编码；Windows 字符串宿主拒绝不能安全表达的 `%`、`!` 和 shell 元字符；临时对象与 synthetic tool invocation 增加实例身份。
- nested workspace namespace、Profile schema、Grok host scope 与最终 prompt carrier 使用同一 identity；重复、过大或不可读 carrier 不再静默跳过路由。
- Codex CLI 探针显式清除 Desktop ambient marker；Desktop 证据必须来自当前 Desktop task 且匹配候选 runtime contract digest，CLI 结果不能替代。
- `generate:control-content` 与 `check:control-content` 现在同步生成并校验 workflow root registry，版本头或公共指令变化不再遗留旧 source digest。
- CI 增加 Linux/Windows 最低兼容控制面、Node 22 LTS、Node 24 LTS full/package/publish 与 Node 26 current compatibility。Node 20 已结束官方维护，不再承担完整发布质量路线。
- Windows Node 18 的 Profile read-trace 插桩排除自身 sink 并增加重入锁、30 秒子进程限时与 1 MiB 文件预算；supported-control-plane job 增加 30 分钟外层限时，避免插桩递归造成 runner 与磁盘无界占用。
- `global-host-config` 验证节点根据 Windows 原生实测 `191,366 ms` 将编排预算从 180 秒调整为 300 秒；保留局部与 CI 外层熔断，避免功能全绿后在收尾阶段产生确定性假失败。

## 兼容性与已知边界

- 这是向后兼容 patch；不新增网络服务、第三方运行时依赖或远程内容面。
- MCP 正文读取从兼容性无绑定放行改为要求持久 ContextRead binding；纯 metadata/plan 入口保持可用。
- Windows DACL 精确保真在缺少可证明平台回执时继续标为条件性 `UNVERIFIED/WARN`，不得由 mode fixture 冒充 PASS。
- DCX2-013（Grok 自定义 rules 权威行为）与 DCX2-015（Profile 深层 merge 契约）仍是明确延期项，不在本版本中暗改。
- 已打开的宿主任务不会热替换运行时；升级后请新建任务或重启宿主以加载新 generation。
