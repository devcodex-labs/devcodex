# v1.20.4 — 审查修复与入口、验证恢复

候选日期：2026-10-10

本次补丁修复全项目审查发现的问题，并补齐发布检查中复现的入口和自动续租缺陷。它保持现有 CLI、MCP、Hook 和六宿主配置契约，已有安装可按正常补丁版本升级。

## 变更

- MCP supervisor 保持客户端已协商的 tools/prompts 契约；worker 重启时复核候选，schema 漂移给出明确重启错误。共享 JSONL reader 拒绝超大帧后继续接收合法请求。
- 修正文件 inventory 截断、损坏 layout marker 的静默回退、正文或否定表述被误判为关闭，以及事务恢复的物理路径校验。
- ContextRead bootstrap 复核 runtime/capability/catalog 身份，保留已消费的冲突记录；SkillRoute、文档和网站同步当前 87 Skill、84 active、3 gray。
- 修复 managed validation 的短 lease 续租，按 task/shard owner 精确 CAS 更新并保持原 hard deadline；过期、撤销、换代和冲突 authority 仍拒绝。
- 普通和最小压缩投影保留经校验的 taskless pending ingress 与有界 Stop 决策，使真实新入口可以继续准入。
- 自动检查点在没有会话环境变量时复用服务器已观察的 ContextRead/回执身份；显式环境身份仍优先，两个服务器来源冲突时拒绝续租和 CP 写入。
- 新候选允许保留能与成功旧发行按同一提交对账的历史失败 CI；新候选自己的 CI 与最终已发布状态仍单独严格验证，不要求改写历史事实。
- 同步 V92 校验器和公开分类说明中的 Skill 数量；源码 CI 明确区分未部署的工作区 Profile，已有工作区继续严格校验。
- 更新两个 brace-expansion 开发依赖锁节点，修复已公告的拒绝服务漏洞；MCP 回归超时输出具体请求阶段和进程诊断。

## 兼容与验证边界

没有新增依赖、公共 API、配置或状态 Schema；用户模型设置保持不变。修复继续使用原 workspace 状态、fenced owner 和检查点事务。

发行须通过当前冻结候选的完整验证、目标提交 CI、精确包资格和安装回读。恢复阶段的源码 CLI 探针与其他宿主 fixture 证据分别记录，不外推为所有原生宿主均通过。

## 发布与恢复

沿用精确制品两阶段发布：tag 工作流构建和资格化，下载同一制品验收后执行 publish-qualified。包已发布但 registry 或 GitHub Release 收尾失败时，按实际 PublishedArtifactReceipt 执行 finalize-only，不重复发布同版本。正式发布事实以 npm registry、Git tag、GitHub Release 和安装回读为准。
