# v1.20.6

> 候选日期：2026-10-18。正式发行状态以 npm registry、Git tag 和 GitHub Release 的实际结果为准。

## 用户可见修复

- 终态重复观察：任务已完成后，再次读取或协调同一个终态回执，不再把已清空的当前操作集误当成原任务的结算集。保留原终态观察及后续操作，不重新授权写入。旧版非退休同步丢失元数据时，仅已通过完整回执、项目及任务校验的同回执重观察可无副作用返回；不虚构历史结算数量，不清除未知效果，首次终态及身份不符继续拒绝。
- 记忆状态：按当前状态声明区分未完成、阻断、进行中和完成，不再把“未完成”“not completed”“incomplete”或“进行中；作者自审完成”投影为已完成。保留已完成状态中对历史阻塞的说明，以及原始记忆文本。
- 索引升级：记忆索引增加解析契约版本检查。旧版索引即使原文、大小和时间未变，也不能继续提供错误状态；查询只读回退，下次正常专用写入再重建，不删除或改写原始记忆。

本版本同时包含 [v1.20.5 候选](./v1.20.5.md) 中的任务恢复、检查点模板、验收、全局适配器与安装文档修复。v1.20.5 的既有验证标签和证据保留，不移动旧标签，不将其资格当作新制品的资格。

## 升级与兼容

公开安装、配置、CP 和任务接口保持。更新安装后，使用公开 `devcodex global-adapters apply` 刷新宿主适配器，并启动新的 CLI/MCP 会话；运行中的旧进程仍使用原代际。没有新增依赖或生产数据迁移。

## 验证边界

新增回归覆盖首次终态、重复观察、后续未结算操作、旧观察及回执身份拒收；记忆回归覆盖中英文否定、部分工作已完成、阻断与已完成历史说明，以及日记/SUMMARY 的索引与回退查询、旧索引失效和零写入读取。

组件回归、真实 Codex CLI 场景、发布前审查和发布级 full 资格分别留证；当前发布结果不能仅由本文件或历史工作流计数推断。正式发布使用同一资格运行产生的精确 tarball，经最终人工确认后续发。
