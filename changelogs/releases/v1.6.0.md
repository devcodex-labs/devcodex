# v1.6.0 — 全维度优化发布

&gt; **发布日期**: 2026-04-17  
&gt; **版本类型**: MINOR  
&gt; **关键词**: npm 分发清洁化 · CLI 可测试化 · 自动化校验 · 单一来源

## 🎯 发布亮点

本版本基于对 DevCodex 项目的全维度深度审查（3 轮 analyze + 10 轮 audit 收敛），聚焦**工程质量短板**与**使用边界模糊**两大类问题，完成 19 项改进。

## 🔴 Breaking / 分发契约变更

### 维护者状态文件不再随 npm 分发（T1）

**影响**：升级用户**不会**再收到本仓库累积的 `violations.md` / `pending-fixes.md` / `gap-registry.md` / `process-improvements.md` 历史记录。

**新分发契约**：
- `data/templates/*.md` — 空骨架模板（分发到用户项目）
- `.devcodex/.maintainer-state/*.md` — 维护者本地状态（**不分发**）

**迁移说明**：用户项目中 `.github/data/` 下的文件来自历次 `devcodex init/update` 拷贝，升级时 `update` 会拷贝空骨架（不覆盖已有内容），用户本地积累的违规记录不会丢失。

## ✨ 新功能

### 自动化校验体系（T3）

新增 6 项统一校验（`scripts/validate.js`）：

| # | 检查项 | 说明 |
|:-:|--------|------|
| V1 | frontmatter 完整性 | 所有 instructions/* 与 skills/*/SKILL.md 必含 applyTo/name/description |
| V2 | 相对链接有效性 | instructions/skills/prompts 内部 `.md` 链接全部可解析（排除代码块） |
| V3 | 子类型五处同步 | plugin.json 与 01-common §Skill按需读取表 子类型一致 |
| V4 | 版本一致性 | package.json / plugin.json / RULES.md / SECURITY.md 版本对齐 |
| V5 | PC4 格式单一来源 | PC4 输出格式定义仅在 18-spec-radar 出现一次 |
| V6 | npm pack 清洁 | 分发产物不含禁止内容（`.devcodex/` / `tests/` / `scripts/`） |

新增脚本：
- `scripts/validate.js` — 综合校验器（V1~V6）
- `scripts/test-pack-clean.js` — npm pack 产物清洁断言
- `scripts/validate-versions.js` — 版本一致性（替代原内联 `test:version`）

新增 CI：
- `.github/workflows/validate.yml` — PR 与 push 自动跑全量校验
