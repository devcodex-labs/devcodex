## Fixed

- 修复 `prompts/precheck-status.prompt.md` 仍停留在 PC0~PC4、且写明 chat 不输出预检查块的问题；当前 dev 模式预检查统一为 PC0~PC7，chat 仅豁免报告与 FC/SC/RC/T 合规块。
- 修复 `prompts/token-setup.prompt.md` 与当前全功能开放策略冲突的问题；Token 当前无需配置，`DEVCODEX_TOKEN` 仅保留为未来授权预留，不再指导用户回显或粘贴 Token。
- 修复报告模板缺少强制头部字段与验证列的问题；开发/分析/优化/场景测试报告补齐 `类型`、`Agent` 与五项验证，fix 报告补 CP 确认记录、三步扫描结果和 incident 秒级字段。
- 修复 chat 与记忆模板沿用旧 `chat/YYYYMMDD.md` 轻量路径的问题；chat 仍写入 daily tasks，只豁免报告。
- 修复 `cp-gate` 与 docs/init 子类型 CP3 豁免之间的冲突；新增 `CP3: N/A（<子类型> 子类型豁免）` 记录口径，并让 hook runtime 与 instruction-fallback 检查识别合法豁免。
- 修复 API verification / scenario-test / dev-testing 对正式归档产物与项目测试目录的路径口径不一致；归档级接口验证双产物统一落任务目录根，脚本只连接外部已运行实例。
- 修复 `scripts/validate.js` 对 prompts 部署同步和模板语义漂移覆盖不足的问题；V8 扩展 prompts 覆盖，新增 V13 语义探针。
- 同步仓内与父级 `.github/.claude` 部署体，消除 V8 stale/missing warning。

## Impact

- 提升模板对 AI 执行路径的约束一致性，降低模板正文漂移导致的误执行风险。
- docs/init 合法 CP3 豁免不会再被 hook/fallback 误判为 CP3 缺失。
- 后续发布验证可自动捕获 precheck、token、report、memory、API verification 等模板语义回归。
