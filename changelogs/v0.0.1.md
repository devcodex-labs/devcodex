# v0.0.1 - 2026-04-04

初始发布 — GitHub Copilot Agent Plugin 架构

## Added

### 核心架构
- **plugin.json**：Copilot Agent Plugin 标准入口，注册 7 个核心 Skills + 11 个 Instructions
- **1 个统一 Agent**（`agents/devcodex.agent.md`）：自动识别意图，路由到 8 个工作流（dev/fix/analyze/audit/self-fix/resume/plan/chat）

### Skills（34 个）
- 核心 Skills（7）：compliance / memory / report / cp-gate / intent / summary / plan
- dev 子类型（8）：default / refactor / database / init / optimization / scenario-test / docs / plan-review
- fix 子类型（3）：default / incident / security
- audit 子类型（8）：common / dimensions / tech-design / requirements / project / report / document / execution-guide
- 其他（8）：analyze-research / self-fix-auto / api-verification / document-sync / impact-review / routing / load-profile / token-check

### Instructions（11 个）
- 00-safety（P2 全局安全底线 S01~S06）
- 01-common（通用约束 C01~C15）
- 02-output-paths（产物路径规范）
- 10-dev / 11-fix / 12-audit / 13-analyze / 14-self-fix（工作流规则）
- 15-memory / 16-report / 17-compliance（核心能力规则）

### Prompt 模板（20 个）
- v4 templates/ 全量迁移 + token-setup 新增

### Hooks（2 个）
- `pre-message.hook.md`：Token 验证 + 意图识别
- `post-session.hook.md`：记忆写入 + 合规检查

### 基础设施
- CLI 工具：`init` / `status` / `update` 命令
- Token 授权系统：Free / Trial / Pro / Enterprise 四层
- GitHub Packages 私有分发：`@vextjs/devcodex`
- 文档站（`website/`）：Rspress 架构
