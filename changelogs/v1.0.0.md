## 📝 变更摘要

v0.0.3 全面重构：项目根骨架重建，规范文件统一英文，需求管理迁移至 `website/docs/requirements/`，版本从 v1.0.0 起。

---

## 🎯 背景说明

### 为什么需要这次变更？

v0.0.3 历经多轮迭代，目录结构混乱，规范文件中英文混用，没有统一的需求管理入口。

### 现状问题

- 规范文件（agents/skills/instructions）中英文混用
- 没有需求管理文档，开发迭代缺乏依据
- 目录结构不清晰，模块边界模糊

### 目标

- 规范文件统一英文编写
- 所有需求统一写入 `website/docs/requirements/`
- 建立清晰的目录结构和模块边界

---

## 📦 变更内容

### ✨ Added（新增）

- `package.json` v1.0.0，包名 `@vextjs/devcodex`
- `plugin.json` 插件元数据（英文描述）
- `index.js` CLI 入口（init / update / status），零依赖
- `.mcp.json` MCP Server 占位配置
- `README.md` 英文主 README
- `CHANGELOG.md` + `changelogs/` 目录（monSQLize 格式）
- `website/` 文档站骨架（Rspress）
- `website/docs/requirements/` 需求文档目录（项目唯一需求来源）
- `website/docs/progress/index.md` 开发进度追踪
- `.devcodex/profile/` 项目规范（01-项目信息 / 02-架构约束 / 03-代码风格）

### 🔄 Changed（变更）

- 版本号从 `0.0.3` 跳跃至 `1.0.0`（重构起点）
- v0.0.3 全部源文件归档至 `v0.03/` 目录

### 🗑️ Removed（移除）

- 旧根目录所有源文件（已归档到 `v0.03/`）
