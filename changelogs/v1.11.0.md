# v1.11.0 — 全模式入口检查与项目现实扩展

> 发布日期：2026-05-26

## Highlights

- 全模式入口检查：PC0~PC7 从 dev-only 提升为所有模式进入实质任务前的基础状态块；dev 模式继续执行 PC4 完整规范雷达与后置 FC/SC/RC/T 合规链，prod 模式 PC4 标注 N/A。
- 项目现实扩展：新增“语义初判 → 目标项目/Profile → 项目现实扩展 → 最终路由”链路，避免只按用户字面意图执行，要求结合项目技术栈、目录、产物落点和验证方式修正工作流。
- Runtime 收口：`lifecycle.cjs` bootstrap 与 Stop closure reminder 改为全模式生效，并补充 prod 模式回归样本。

## Changed

- 更新 `instructions/00-safety.instructions.md`、`01-common.instructions.md`、`17-compliance.instructions.md`、`18-spec-radar.instructions.md` 与单源 `instructions.md`，统一 S07/C18、ENV_MODE 行为表、入口检查模板和项目现实扩展规则。
- 更新 `skills/compliance`、`skills/intent`、`skills/load-profile`、`skills/routing`，明确入口检查所有模式启用、意图识别分层输出、Profile 后置扩展结论和路由修正规则。
- 更新 `prompts/precheck-status.prompt.md`，将输出模板改为“入口检查（[DEV/PROD] 模式）”，补入 PC1/PC3 的项目现实扩展字段。
- 更新 README、RULES、网站开发指南与预检查流程图，补齐用户面真相源说明。
