# v1.11.1 — Codex 宿主闭环与执行复审增强

> 发布日期：2026-05-27

## Highlights

- Codex adapter 闭环：默认 `devcodex init/update` 已覆盖 Copilot、Claude Code、Codex 三宿主同步，`instructions.md` 继续作为 AGENTS/CLAUDE/Copilot instructions 的单源规范。
- Hook 宿主契约修复：补齐 `forbid / require_completion / warn_continue / log_only` 拦截状态机、危险命令一次性确认、Codex/Claude 输出契约 direct replay 与审计日志。
- 执行闭环增强：新增 ECR 执行闭环复审、Intent Expansion Card、ConfirmationRequest 与报告推荐结论要求，降低长会话压缩后的假完成风险。

## Changed

- 更新 README、`instructions.md`、`instructions/01-common`、`10-dev`、`11-fix`、`13-analyze`、`17-compliance`，统一 ECR、意图扩展、确认请求与推荐结论语义。
- 更新 `skills/compliance`、`cp-gate`、`dev-default`、`dev-plan-review`、`fix-default`、`intent`、`load-profile`、`report`，把闭环复审、宿主能力、推荐结论和确认抽象纳入执行规则。
- 更新 report/precheck prompt 模板，要求多建议或决策场景必须输出推荐项和推荐理由。
- 更新网站开发指南与执行/预检查/报告/流程图规范页，保持用户文档与运行规则同源。

## Fixed

- 修复 Codex 新会话入口提醒、multi-project warning、status/doctor Codex 诊断与 ChatGPT/Codex 能力表述边界。
- 修复记忆与报告 `<agent>` 落点规则：当前实际宿主优先，profile `agent` 仅作为兜底。
- 修复 workspace-namespace 下 MCP memory scope 从工作区根调用时的歧义，要求显式传 `project` 或 `scope:"workspace"`。
- 修复 Codex `Stop/UserPromptSubmit/PreCompact` 与 Claude `PreCompact` 的宿主 block 输出契约，并补 direct replay 防回归探针。
