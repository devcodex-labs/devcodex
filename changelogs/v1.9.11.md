# v1.9.11 — Auto v1.1 runtime 收口 + 白名单门禁落地

> **类型**: PATCH

## Fixed

- 将 Auto v1.1 的正式入口收敛为显式 `@devcodex-auto`，不再把 `auto:` / `/auto` / profile `executionMode` 误写成当前已生效能力。
- 在 `hooks/_runtime/lifecycle.cjs` 中新增 `executionMode` 状态与 Auto 白名单门禁：仅对白名单路径自动推进，非白名单默认回确认模式，危险命令仍保持阻断。
- 补齐 `scripts/test-hooks-runtime.js` 的 auto 专属回归用例，覆盖 executionMode 写入、白名单放行、非白名单阻断与危险命令阻断。
- 扩展 `scripts/validate.js` V14，校验 agent / instructions / skills / runtime / test / README 的 auto 语义联动。
- 同步 README 与父级 `.github/.claude` 部署副本，消除“源码已改、部署滞后”的 V8 噪音。

## Validation

- `npm run test:all`
- `node scripts/validate.js`
- `npm view @vextjs/devcodex version --registry https://npm.pkg.github.com`（发布前确认当前 registry 为 `1.9.10`，需要 bump 后才能 publish）

## Impact

- Auto 模式从“仅 CP 自动通过”提升为可执行的最小 runtime 闭环，但边界仍保持在 hook-enforced + 白名单路径，避免过度承诺。
- 非 auto 模式继续走原 confirm 路径；完整回归已覆盖 validate、hooks runtime 与 pack-clean。
- 后续如果要推进 Auto v1.2/v2，可在现有 executionMode 与 V14 基础上继续扩展，不需要重做本轮收口。

## Breaking Changes

无。
