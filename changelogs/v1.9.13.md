## Fixed

- `instructions/10-dev.instructions.md` 把 `dev.default` 主链显式收敛为“执行 → 轻量复审收敛 → 完成”，并新增契约驱动型需求的“目标文档前置”规则。
- `instructions/11-fix.instructions.md` 与 `instructions/17-compliance.instructions.md` 同步把 `fix` 的轻量复审收敛提升为执行后的正式阶段表达，`SC15` / `T7` 改为感知“执行 → 复审收敛 → 完成”完整链路。
- `skills/dev-default/SKILL.md` 把 `N6` 从“方案一致性验证”统一为“轻量复审收敛”，并明确其内部包含关键产物对照、阻断问题复审与完成判定。
- `skills/dev-docs/SKILL.md` 新增契约驱动型目标文档分流，明确 `light-api` / `frontend-api` 两种阅读型文档模式，以及它们与 `api-verification` 的职责边界。
- `skills/api-verification/SKILL.md` 与 `prompts/api-verification.prompt.md` 收紧为“归档级可执行验证双产物”，不再承担读者向的轻量接口文档职责。
- `README.md` 的使用示例和执行原则同步更新为“执行 → 轻量复审收敛 → 完成”，并补入目标文档前置与轻量文档 / 前端文档 / 归档验证的边界说明。
- `hooks/_runtime/lifecycle.cjs` 为 dev 模式最终回复新增两类 `Stop` 兜底提醒：
  - 缺少 `🛡️ DEV 模式 | 合规检查` 状态块
  - 缺少 FC5 双行产物路径输出
- `hooks/_runtime/lifecycle.cjs` 的 `artifactPaths` 检测进一步收紧为：只有出现在 `📂 本次会话产物` 区块下的链接 + 绝对路径双行，才视为正式产物路径输出。
- `scripts/test-hooks-runtime.js` 新增最终回复闭环回归样本，覆盖：
  - 缺少合规块与产物路径时应提醒
  - 只有“参考文件”区块时仍应提示 FC5 缺失
  - 完整的 artifact section 输出时不应再提醒
