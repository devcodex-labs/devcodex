# DevCodex 隐私政策

> **版本**: v1.0
> **生效日期**: 2025-01-01

## 收集的数据

| 数据类型 | 是否收集 | 说明 |
|---------|:-------:|------|
| 代码内容 | ❌ | 不收集，仅在本地处理 |
| 记忆文件 | ❌ | 存储在用户本地 |
| 匿名使用统计 | ✅（可选） | 工作流类型/频率，无个人信息 |
| Token 使用情况 | ✅ | 用于授权验证和计费 |
| 错误日志 | ✅（可选） | 不含代码内容，用于改进产品 |

## 数据存储

- 所有代码相关数据**仅在本地处理**，不传输至 DevCodex 服务器
- Token 验证通过加密 HTTPS 请求进行
- 使用统计数据匿名化处理，不可追溯到个人

## 用户权利

- 可随时关闭匿名统计（设置 `DEVCODEX_TELEMETRY=false`）
- 可申请删除账号数据：privacy@devcodex.dev
