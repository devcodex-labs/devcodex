## 6. 请求示例

```bash
curl -X POST "<baseUrl>/api/..." \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "field": "value"
  }'
```

## 编写要求

1. 默认用调用方视角写，不展开内部实现细节
2. 必须写清楚服务归属、模块和 `base path`
3. `frontend-api` 模式必须补页面/模块入口与前置条件
4. 必须至少给出 1 个请求示例、1 个成功响应示例、1 个错误响应示例
5. Markdown 文档必须包含 `## 目录导航`
6. 不强制生成 `.http` / `.cjs`；如需归档级验证，转交 `api-verification`
