# 需求变更概况模板

> **路径**: `.devcodex/**/requirements/<中文描述>/00-需求变更概况.md`
> **触发**: 调整 / 修改 / 补充已确认需求；需求变更 CP1 前置
> **填写对象**: 需求方 / 产品 / 运营 / 客户 / 内部使用方 / 变更提出方

---

## 编写指引

> ⚠️ 本模板只用于**需求变更**：已有 `01-需求确认.md`、历史 `01-需求概述.md`、正式 PRD、website requirement 或已确认决策，现在要做增量调整。
> ⚠️ 不得把需求变更当成纯新需求；必须先锚定原需求基线，再描述变更前后差异。
> ⚠️ 若是新增能力且没有既有确认基线，请使用 `00-需求概况.md`。
> ⚠️ 若是 Bug / 异常 / 已承诺行为与实际不一致，请使用 `.devcodex/**/bugs/<问题>/00-问题概况.md`。
> ⚠️ 变更提出方不填写验收标准、测试用例、数据库字段、接口 Schema 或技术实现；技术影响由后续技术方案派生。
> ⚠️ AI / 产品必须根据本文件生成或更新 `01-需求变更确认.md`，并在确认后回写目标 `01-需求确认.md` / 正式需求文件 / website requirement 的变更记录。
