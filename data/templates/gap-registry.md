# 维度盲区 / 检测盲点登记（template）

> **文件定位**：模板。`devcodex init` 复制为用户项目 `.github/data/gap-registry.md`。  
> **使用**：审查中遇到无对应维度的问题，或 R2+ 自我审视发现 M1~M4 盲点时登记。  
> **维护者记录**：`.devcodex/.maintainer-state/gap-registry.md`。

---

## 格式规范

| 字段 | 说明 |
|------|------|
| 编号 | `GR-NNN` |
| 日期 | `YYYY-MM-DD` |
| 类型 | `维度盲区` / `检测盲点` |
| 盲点类型 | M1/M2/M3/M4（检测盲点）或 N/A（维度盲区） |
| 简述 | 一句话 |
| 建议维度 | 拟新增维度名或 N/A |
