# 待修复清单（template）

> **文件定位**：模板。`devcodex init` / `devcodex init --claude` 复制为目标项目运行时 `data/pending-fixes.md`（Copilot: `.github/data/pending-fixes.md`；Claude Code: `.claude/data/pending-fixes.md`）。
> **使用**：PC4 三轴检测出 PF 标记后，AI 追加到此表；修复完成后标注 ✅。
> **维护者自身的 PF**：不在本包内分发；启用 `workspace-namespace` 时写入对应 active-root，例如 `<工作区根>/.devcodex/<project>/data/pending-fixes.md`。

---

## 字段规范

| 字段 | 说明 |
|------|------|
| 编号 | `PF-NNN` |
| 登记时间 | 精确到分钟，格式 `YYYY-MM-DD HH:mm` |
| 规范化意图 | `record.spec-defect` |
| 置信度 | 高 / 中 / 低 |
| G 码 | `G1~G11`（见 `18-spec-radar`）|
| Axis | `A` / `B` / `C` / `A+B` 等多轴组合 |
| 触发来源 | PC4 / audit / ECR / 用户建议 / validate |
| 缺陷类型 | 缺失 / 冲突 / 滞后 / 外部假设失效 / 完成边界缺失 / 字段不足 / 路径漂移 / 检测盲区 |
| 简述 | 一句话描述规范缺陷 |
| 修复方案 | 计划怎么修 |
| 修复时间 | 完成修复时间，未完成为 `—`；关闭链需满足 `登记时间 ≤ 修复时间 ≤ 验证时间/关闭时间` |
| 是否已验证 | 是 / 否 / 部分 |
| 验证时间 | 完成验证时间，未完成为 `—`；不得早于登记时间或修复时间 |
| 验证证据 | validate/test/CRS/SCV/ECR 证据 |
| SCV要求 | 是否需要 SCV，填 `是` / `否` |
| 关联 VL/GAP/PI | 若为 G5 重复违规或由违规/盲区升级，填对应编号 |
| 关闭时间 | 关闭时间，未关闭为 `—`；不得早于登记时间或修复时间 |
| 状态 | 🔄 / ✅ / ⚠️ |
