# 过程改进记录（template）

> **文件定位**：模板。`devcodex init` 复制为用户项目 `.github/data/process-improvements.md`。  
> **使用**：C17 触发时追加 PI 条目。  
> **维护者记录**：`.devcodex/.maintainer-state/process-improvements.md`。

---

## 字段规范

| 字段 | 说明 |
|------|------|
| 编号 | `PI-NNN` |
| 日期 | `YYYY-MM-DD` |
| 触发场景 | 用户建议的执行策略 |
| 是否纳规 | ✅ 已纳入规范 / 🔄 待评估 |
