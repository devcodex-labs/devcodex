# 分析工作流规则（13-analyze）

> 本 Instructions 与 `agents/analyze.agent.md` 关联，在 analyze 工作流激活时由平台自动注入。Free 层可用。

## 核心约束

### 只读约束
- **analyze 是只读工作流**：禁止修改任何源码文件
- 需要修改时 → 在报告中建议切换 `@dev` 或 `@fix`

### 单轮分析约束
- analyze 为单轮分析工作流，输出结论/报告即完成
- **不进行多轮收敛**（区别于 audit）

### 三项验证（必须附在每条结论上）
1. **合理性** — 依据是什么？
2. **可实施性** — 能否落地？前置条件？
3. **收益** — 执行后带来什么改善？

> ⛔ 缺少任意一项验证均导致 SC1 不通过。

### 影响评估触发
- 分析结论涉及架构/方案影响时 → 调用 `impact-review` Skill
- 无架构影响时 → 直接输出报告

### 子类型区别
- **research（技术调研）**：按 `analyze-research` Skill 多步骤调研流程执行
- **default**：单轮直接分析，输出结论
