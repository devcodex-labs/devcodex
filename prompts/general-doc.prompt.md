# 通用文档模板

> **触发**: `dev-docs/SKILL.md` 的非契约驱动型文档场景
> **适用**: 架构文档 / 开发指南 / 迁移指南 / 治理说明 / 运行手册
> **要求**: 生成的 Markdown 文档必须包含 `## 目录导航`

---

## 文档头部

```markdown
# <文档名称>

> **文档类型**: architecture / guide / migration / governance / runbook
> **适用对象**: <谁会阅读这份文档>
> **适用范围**: <模块 / 服务 / 工作区>
> **更新时间**: YYYY-MM-DD
```

## 目录导航

```markdown
## 目录导航

- [1. 文档目的](#1-文档目的)
- [2. 适用范围](#2-适用范围)
- [3. 前置条件](#3-前置条件)
- [4. 核心内容](#4-核心内容)
- [5. 操作步骤 / 使用方式](#5-操作步骤--使用方式)
- [6. 风险与注意事项](#6-风险与注意事项)
- [7. 常见问题](#7-常见问题)
- [8. 参考资料](#8-参考资料)
```

## 编写要求

1. 默认使用调用方或读者视角写，不把实现细节塞满正文
2. Markdown 文档必须包含 `## 目录导航`
3. 若文档本身成为后续实现锚点，应在正文中显式引用关联需求、方案或接口文档
4. 仅保留与当前文档类型相关的章节；无关章节可标 `N/A`
