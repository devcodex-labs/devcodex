# 证据与完成

## 你在问什么

怎样才算做完？不是模型说「已完成」，而是有验证、报告和剩余风险记录。

## 心智模型

完成要能回答：跑了什么、结果是什么、还剩什么没做、哪些不能声称。

只读任务的证据是分析结论和边界。改文件的任务还要有测试或构建结果，以及确认记录。

## 示例

修好一个失败测试后，报告应写明命令和退出码，而不是只写「测试过了」。  
审查任务应指出看过哪些路径、什么没看，而不是给一句总评。

## 边界

- 没跑的验证不能写成已通过。
- 测试绿不能代替确认或发布授权。
- 公开站不展示内部检查表、Receipt 或 PC0 施工日志。
