# `resume`：跨会话续接

## 适用 / 不适用

适用：同一项目里继续昨天没做完的任务。  
不适用：全新题目（应直接说新意图，不要假装续接）。

## 是否改文件

取决于被恢复的任务。原来只读，续接后仍只读。

## 阶段

定位任务 → 读文件真相 → 回到原工作流和阶段。

## 确认边界

不因为换了会话就省略原来的确认。发布、删除、越界仍然要再授权。

## 产物

续接记录、原任务的后续产物。

## 验证

先核对当前文件是否还对得上记忆，再往下做。

## 完成条件

原任务按原工作流的完成条件结束，或明确还差什么。

## 示例请求

```text
继续公开站点内容与事实生成升级任务
```

故事见 [跨会话续接案例](/examples/resume)。
