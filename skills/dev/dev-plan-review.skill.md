# Dev Plan Review Skill

## 触发条件

用户要求审查实施计划（CP3 产物），或在开始执行前主动进行计划质量审查。

## 豁免项

- 豁免 `plan-review`（本身即为计划审查，不递归）
- 豁免 `impact-review`（只读工作流，不修改代码）
- 简化流程：单轮分析，无需 CP 关卡

## 审查维度

| 维度 | 检查项 |
|------|--------|
| 完整性 | 任务是否可独立执行 + 依赖关系是否标注 |
| 可行性 | 每个任务是否有明确完成标准 + 时间是否合理 |
| 风险覆盖 | 高风险步骤是否有回滚方案 |
| 与方案一致 | 实施计划与 CP2 技术方案是否对应 |
| CP3 格式 | 是否符合 `cp-gate.skill.md` 的 CP3 格式标准 |

## 执行规则

1. 读取 CP3 实施计划文档
2. 按五维度逐项审查
3. 输出审查报告（问题列表 + 修改建议）
4. 审查仅提出建议，不直接修改计划（修改由用户决定）

## 输出格式

```markdown
## 计划审查报告

**审查结论**：通过 / 有条件通过 / 需修订

### 问题列表
| # | 维度 | 问题描述 | 修改建议 |
```
