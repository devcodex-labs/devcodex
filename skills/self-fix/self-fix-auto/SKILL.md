# Self Fix Auto Skill

## 职责

规范文件（specs/、instructions/、agents/、skills/）的自动化修复，按修复分级执行，遵循 V1~V6 闭环验证。

## 修复分级

### 自动级（直接修复）

AI 可在**无需用户确认**的情况下直接修复（白名单 A1~A5）：

| 编号 | 类型 | 示例 |
|------|------|------|
| A1 | 数值同步 | 文件数量、编号总数不一致 |
| A2 | 格式修正 | 表格对齐、代码块缺少语言标记 |
| A3 | 缺失字段 | frontmatter 缺少 version 字段 |
| A4 | 断链修正 | 内部相对路径链接 404 |
| A5 | 编号修正 | D 编号/C 编号/维度编号排列错误 |

### Pending 级（暂存等待）

超出白名单范围但确认是问题时，写入 `data/pending-fixes.md`：

```markdown
## Pending Fix #N
- 文件：<路径>
- 问题：<描述>
- 建议修复：<方案>
- 发现时间：<YYYY-MM-DD>
```

### 拒绝级

涉及规范语义变更（修改 spec 的规则含义）时**拒绝自动修复**，提示用户通过 dev 工作流处理。

## 闭环验证（V1~V6）

修复后必须执行：

| 编号 | 验证项 |
|------|--------|
| V1 | 修复前后内容对比（diff 可读） |
| V2 | 被修复文件语法正确（Markdown 结构完整） |
| V3 | 内部链接有效（修复的链接目标存在） |
| V4 | 跨文件引用一致（引用本文件的其他文件未受影响） |
| V5 | frontmatter 完整（必填字段无缺失） |
| V6 | 编号唯一性（修复后无重复编号） |
