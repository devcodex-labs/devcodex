# ⑤ 前置状态汇总流程图

> 本页聚焦主流程中的 `⑤ 前置状态汇总` 阶段。  
> 当前仍为流程定义阶段，下面是 v1.0.0 的前置状态汇总骨架，不代表已实现代码。

---

## 前置状态汇总主链

```mermaid
flowchart TD
    IN["接收前置节点结果（预检查 / 安全检查 / 摘要 / 记忆）"]
    COLLECT["收集可用状态信息（规则基线 / 上下文 / 记忆状态 / 风险）"]
    NORMALIZE["标准化为统一状态视图"]
    CHECK{"信息是否足够支撑开发前闸门判断?"}
    COMPLETE["补齐缺失信息或标注不确定项"]
    OUT["输出前置状态汇总，进入开发阶段合规检查"]

    IN --> COLLECT --> NORMALIZE --> CHECK
    CHECK -->|是| OUT
    CHECK -->|否| COMPLETE --> OUT
```

---

## 阶段输出要求

1. 汇总必须覆盖：规则基线、上下文完整度、记忆状态
2. 明确标注“已确定 / 待补齐 / 有冲突”的状态项
3. 输出结果可直接供开发阶段合规检查使用
