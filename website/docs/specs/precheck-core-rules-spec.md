# 核心规则

> 本页是「预检查流程图」的下级说明，聚焦步骤②：读取核心规则 `RULES.md`。

---

## 作用

`RULES.md` 是预检查入口规则，定义整条强制执行主流程与节点元数据来源。

---

## 读取要求

1. 收到用户消息后必须读取 `RULES.md`。  
2. 必须提取并遵循主流程图，不得跳过节点。  
3. 必须识别并使用 NODE_META 信息作为后续节点规范加载依据。  

---

## 输出要求

读取本文件后，至少应明确：

1. 当前会话将执行的主流程骨架。  
2. 预检查固定步骤与后续节点关系。  
3. 后续节点的规范加载依据（NODE_META）。
