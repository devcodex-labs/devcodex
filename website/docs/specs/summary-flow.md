# ③ 写入摘要流程图

> 本页聚焦主流程中的 `③ 写入摘要` 阶段。  
> 当前仍为流程定义阶段，下面是 v1.0.0 的摘要流程骨架，不代表已实现代码。

---

## 写入摘要主链

```mermaid
flowchart TD
    IN["接收上游状态（安全检查通过 / 操作级违规后继续）"]
    EXTRACT["提取本轮核心信息（目标 / 约束 / 边界）"]
    NORMALIZE["标准化表达（避免冗余与歧义）"]
    SUMMARY["生成会话摘要（用于后续记忆检索）"]
    CHECK{"摘要是否足够支撑后续检索?"}
    REFINE["补充关键上下文后重写摘要"]
    OUT["输出摘要并进入记忆检索阶段"]

    IN --> EXTRACT --> NORMALIZE --> SUMMARY --> CHECK
    CHECK -->|是| OUT
    CHECK -->|否| REFINE --> SUMMARY
```

---

## 阶段输出要求

1. 摘要必须覆盖：本轮目标、关键约束、执行边界
2. 摘要应服务后续“记忆检索”，避免只写表面描述
3. 摘要应简洁且可复用，不应夹杂执行细节噪音
