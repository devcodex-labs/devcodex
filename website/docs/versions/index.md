# 版本列表

> 本区版本号描述需求文档快照：当前活动线是 `1.0.1`。可安装 npm package 的当前发布版本是 `1.15.2`；两者生命周期不同，不应据此推导 registry 中存在 `1.0.1` 包。

> 版本文档采用 **series / release** 两级结构：先进入 `v1`、`v2` 等系列，再进入具体版本如 `1.0.0`、`2.0.0`。  
> 这样同一大版本下可以继续承载 `1.0.1 / 1.1.0 / 1.2.0` 等多次迭代，而需求文档始终挂在**具体版本**下面。
