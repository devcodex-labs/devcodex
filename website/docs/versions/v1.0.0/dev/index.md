## 文档结构说明

每个需求下包含四类文档：

| 文件 | 内容 | 更新时机 |
|------|------|---------|
| `design.md` | 技术方案（CP2 产物）| 方案确认后创建，有重大变更时更新 |
| `plan.md` | 实施计划（CP3 产物）| 每个阶段开始前制定 |
| `progress.md` | 多阶段进度（Phase 1 / Phase 2...）| 每次会话后更新 |
| `decisions.md` | 关键决策记录（时间 / 背景 / 选择 / 原因）| 每次重要决策后追加 |
