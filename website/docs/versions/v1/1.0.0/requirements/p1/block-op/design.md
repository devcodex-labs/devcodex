## 方案概述

操作级违规处理逻辑内联在 `devcodex.agent.md` §② 的操作级违规分支中，按违规类型分级处理。

---

## 核心设计

当 S01/S04/S06 触发操作级违规时：
1. **阻断违规操作** — 拒绝执行，不产生副作用
2. **引用规则编号** — 向用户说明阻断原因（如"S01：不可逆操作需确认"）
3. **生成合规替代** — 提供可达到同等目的的合规方案
4. **分级执行** — 不可逆操作等待 yes/no；可逆操作输出提示后直接执行替代

## 风险与约束

- 不可逆操作的 yes/no 必须是用户明确输入，全自动模式也不能跳过
- 替代方案必须等效于用户原始目的，不能简单拒绝
