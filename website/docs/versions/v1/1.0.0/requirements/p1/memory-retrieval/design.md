## 方案概述

## 核心设计

按 `devcodex.agent.md` §④ 定义的读取策略：

| 场景 | 读取范围 |
|------|---------|
| 正常会话 | 今日 + 昨日文件（并发读取）|
| resume | 最近 14 天文件 |
| 今日不存在 | 仅昨日 |
| 解析失败 | 重命名 `.bak.md` + 新建 |

命中 → 合并上下文 → 检测冲突/未完成任务 → 标记 resume 提示  
未命中 → 记录状态 → 继续

## 风险与约束

- 禁止默认读取超过昨日以前的文件（除 resume）
- 禁止使用 glob/find 扫描 `.memory/` 隐藏目录
- 检索阶段为只读，不产生写入
