> **状态**：🟡 当前活动版本（骨架已建立）  
> **基础**：承接 [v1.0.0](/versions/v1/1.0.0/) 基线快照

## 版本定位

- `1.0.0` 继续保留历史基线与归档记录。
- `1.0.1` 从现在起承接新的增量变更。
- 后续 patch 迭代继续沿用同级新版本目录推进，例如 `1.0.2`。

- 所有新增需求、Bug 修复、发布准备优先落到 `website/docs/versions/v1/1.0.1/` 下。

- 发版前同步目标版本目录、`package.json`、`plugin.json` 和对应 CHANGELOG。
