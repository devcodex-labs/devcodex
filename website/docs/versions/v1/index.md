# v1 系列

> v1 系列用于承载 `1.x.y` 的本地文件版 DevCodex 演进。  
> `1.0.0` 是已存档的**基线快照**；`1.0.1` 已建立为当前活动版本入口。后续新增需求、Bug 修复和发布准备，不再继续回写 `1.0.0`，而是在同级具体版本目录中继续推进。

## 系列概览

| 版本 | 状态 | 说明 |
|------|------|------|
| [1.0.1](/versions/v1/1.0.1/) | 🟡 当前活动版本 | 已建立版本骨架与导航入口，后续新增需求和修复从这里继续 |
| [1.0.0](/versions/v1/1.0.0/) | ✅ 基线快照 | 历史基线与归档边界化页面；不再承载后续新增需求 |

## 版本层级

```text
v1 系列
├── 1.0.0   ← 基线快照（历史）
├── 1.0.1   ← 当前活动版本
├── 1.0.2   ← 后续 patch 迭代版本
└── ...
```

> 需求文档只挂在具体版本下，不直接挂在 `v1` 系列页下。

## 说明

- `1.0.1/` 已作为当前活动版本目录建立，后续新增需求、Bug 修复、发布前准备应优先写入该目录。
- 后续新增需求、Bug 修复、发布前准备，统一在 `website/docs/versions/v1/<next-version>/` 创建独立版本目录，不再继续写入 `1.0.0/`。
- `1.0.0/` 只允许继续做历史纠偏、归档边界化和事实性修正，不再承载新增需求条目。
- 发版前必须同步目标版本目录、`package.json`、`plugin.json` 和对应 CHANGELOG；至少保证分发版本与文档版本不再分裂。
