# v1 系列

> v1 系列用于承载 `1.x.y` 的本地文件版 DevCodex 演进。  
> 当前仅维护 [1.0.0](/versions/v1/1.0.0/)。

## 系列概览

| 版本 | 状态 | 说明 |
|------|------|------|
| [1.0.0](/versions/v1/1.0.0/) | 📝 需求整理中 | 当前工作的唯一有效版本快照 |

## 版本层级

```text
v1 系列
└── 1.0.0
    ├── 版本概述
    ├── CHANGELOG
    ├── requirements/
    └── release/
```

> 需求文档只挂在具体版本下，不直接挂在 `v1` 系列页下。

## 说明

- 后续 `1.0.1`、`1.1.0`、`1.2.0` 将继续放在 `v1/` 目录下。
- 当版本差异只涉及补丁级文案时，可以先复用当前文档快照；当需求或流程明显变化时，再新增独立版本目录。
